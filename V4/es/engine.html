Vista de selección de engines

El selector de engines permite explorar y seleccionar engines para el tipo elegido, que puede ser uno de los siguientes:

  • MIDI Synth
  • Audio Effect
  • MIDI Tool
  • Audio Generator
  • Special

Accederá a esta vista al añadir una chain nueva o al añadir o reemplazar procesadores en una chain existente.

La vista se divide en 3 columnas:

  • [Izquierda] Lista de categorías del tipo elegido.
  • [Centro] Lista de engines de la categoría seleccionada. De forma predeterminada, solo se muestran los engines habilitados. Consulte el modo avanzado más abajo.
  • [Derecha] Información sobre el engine resaltado, compuesta por:
    • Calidad: valorada de 0 a 5 estrellas.
    • Complejidad: valorada de 0 a 5 ruedas.
    • Descripción: un breve texto que describe las características del engine.

Puede realizar las siguientes acciones:

  • Girar el mando 3 (LEARN/SHOT) para desplazarse por la lista de categorías.
  • Girar el mando 4 (SELECT) para desplazarse por la lista de engines.
  • Pulsar el mando 4 para seleccionar el engine resaltado y cerrar el selector de engines.
  • Mantener pulsado el mando 4 para activar el modo avanzado, que muestra TODOS los engines y permite activarlos o desactivarlos.
  • Pulsar el mando 3 para abrir la pantalla de información ampliada y leer las descripciones completas.
  • Pulsar el mando 2 (BACK) para volver a la vista anterior.

También puede usar la pantalla táctil en las listas de categorías y engines. Al tocar la columna de información, se abrirá la pantalla de información ampliada.

Modo avanzado

Para activar el modo avanzado, mantenga pulsado el mando 4. En este modo se muestra la lista completa de engines, incluidos los engines deshabilitados, que normalmente están ocultos. Puede marcar o desmarcar los engines para activarlos o desactivarlos. Pulse BACK para volver al modo normal.
