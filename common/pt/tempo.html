Vista de tempo

A vista de tempo permite controlar a base de tempo do zynthian, utilizada para sequenciação, arpeggiators, etc.

Rode o botão 1 para ajustar o valor de BPM entre 10 e 420 BPM. Prima e rode para ajustar em incrementos de 0,1 BPM. Tenha em atenção que o tempo em BPM pode ser automatizado através de frases do launcher. Este controlo só está disponível quando é utilizado o relógio interno.

Rode o botão 2 para ajustar o controlo Metronome Mode, que configura o metrónomo do zynthian. Tem os seguintes valores:

  • OFF: O metrónomo está desativado.
  • AUTO: O metrónomo soa quando há uma sequência em reprodução e para no final do compasso após parar a última sequência.
  • ON: O metrónomo está sempre em reprodução.
  • INTRO: O metrónomo soa até começar uma sequência. Pode utilizar esta opção como contagem de entrada quando não quiser ou não precisar que o metrónomo soe durante a atuação.
  • NO ACCENT: O metrónomo está sempre em reprodução, mas sem acentuar o primeiro tempo de cada compasso. Funciona mais como um metrónomo tradicional, utilizado apenas para marcar o tempo e não como base de tempo.
  • SILENT: O metrónomo funciona, mas não produz som. Esta opção pode ser útil para iniciar o transporte quando não há sequências em reprodução. Alguns plugins poderão beneficiar desta opção.

Rode o botão 3 para ajustar o volume do metrónomo.

Nota: O som de clique do metrónomo é encaminhado para a chain principal através do respetivo envio de mistura auxiliar, que permite controlar individualmente o nível, o balanço, etc. O leitor de áudio global partilha esta mistura auxiliar.

Rode o botão 4 para alterar a fórmula de compasso (tempos por compasso). As alterações à fórmula de compasso são aplicadas no início do compasso seguinte.

Nota: O tempo (BPM) e a fórmula de compasso (tempos/compasso) podem ser automatizados através de frases do launcher.

Relógio externo

Se for utilizado um relógio externo, o controlo BPM é substituído pelo Clock Divider. O valor predefinido do divisor de relógio é 24 PPQN, que é o utilizado pelo MIDI clock, mas pode ser ajustado para suportar outras frequências de relógio externo no intervalo de 1 a 48 PPQN.

O relógio interno funciona a 1920 PPQN e utiliza um phase locked loop (PLL) para obter este relógio de alta resolução a partir do relógio de entrada lento. Para utilizar um relógio externo, selecione "MIDI Clock Source" para uma entrada MIDI na vista Entrada MIDI.

Tap-Tempo

Existe um visor grande com o valor BPM, no qual pode tocar para definir o tempo. Também pode tocar no botão de tempo para o definir.
