Sprachunterstützte Benutzeroberfläche: ZynVoice

Zynthian verfügt über einen umfangreichen Text-to-Speech-Assistenten namens ZynVoice, der für sehbehinderte Benutzer entwickelt wurde. Mit ZynVoice lässt sich das Gerät vollständig über die Hardware-Tasten und -Regler bedienen. Akustische Hinweise unterstützen Sie dabei. Die Navigation und Bedienung werden durch Sprachausgaben und Töne unterstützt. ZynVoice verwendet ein zusätzliches Audio-Interface oder eine Soundkarte, um eine Audioausgabe bereitzustellen, die von der Hauptausgabe getrennt ist. So bleibt die Audioausgabe für die Produktion unbeeinflusst, während die ZynVoice-Ansagen an das persönliche Monitoring des Benutzers ausgegeben werden.

Erste Schritte

Schließen Sie ein Audiogerät an, das ZynVoice verwenden kann, zum Beispiel eine USB-Soundkarte. Dieses Gerät muss weder teuer sein noch eine hohe Klangtreue bieten. Ein Gerät für 2 $ hat sich als ausreichend erwiesen.

Merken Sie sich die folgenden Begriffe, die im gesamten Hilfesystem verwendet werden:

  • Drücken: bedeutet, eine Taste kurz zu drücken und wieder loszulassen.
  • Kräftig drücken: bedeutet, eine Taste etwa 1,5 Sekunden lang zu drücken und anschließend loszulassen.
  • Lange drücken: bedeutet, eine Taste mindestens 2 Sekunden lang gedrückt zu halten.

Die Taste F4 ist als ZynVoice-Taste festgelegt. Bei einem zynthian V5 befindet sich diese Taste unten rechts auf dem Tastenfeld mit 20 Tasten. Bei einem zynthian V4 befindet sie sich rechts neben den vier Tasten in der Mitte. ZynVoice ist standardmäßig deaktiviert, lässt sich aber ganz einfach durch langes Drücken der ZynVoice-Taste aktivieren. Dadurch wird ZynVoice abwechselnd aktiviert und deaktiviert. Wenn Sie ZynVoice aktivieren, hören Sie die Ansage „ZynVoice aktiviert“. Wenn Sie ZynVoice deaktivieren, hören Sie entsprechend die Ansage „ZynVoice deaktiviert“.

Ist ZynVoice aktiviert, hören Sie Ansagen, während Sie durch die Benutzeroberfläche navigieren und Aktionen ausführen. Beim Aufrufen einer Ansicht wird beispielsweise deren Name angesagt, damit Sie wissen, an welcher Stelle im Navigationsbaum Sie sich befinden. Wenn Sie durch Listen navigieren, wird jeder Listeneintrag angesagt.

Vor jeder Ansage gibt es eine kurze Verzögerung von etwa 0,2 Sekunden. Bei Bedarf können Ansagen in eine Warteschlange gestellt werden, meist werden sie jedoch durch die jeweils neueste Ansage unterbrochen. Beim Navigieren durch eine Liste können beispielsweise Einträge übersprungen werden.

Mit der ZynVoice-Taste können Sie die aktuelle Ansage stoppen. Wenn ZynVoice gerade nichts ausgibt, löst ein Druck auf die ZynVoice-Taste eine Kontextansage aus. Standardmäßig wird dabei der Name der aktuellen Ansicht angesagt. Zusätzlich können Informationen zum Kontext der Ansicht ausgegeben werden, beispielsweise der hervorgehobene Eintrag einer Liste. Durch langes Drücken der ZynVoice-Taste wird ZynVoice abwechselnd aktiviert und deaktiviert.

Neben Sprachausgaben gibt ZynVoice jede Sekunde einen kurzen Ton aus, solange die Benutzeroberfläche beschäftigt ist, beispielsweise beim Laden eines snapshot. Das Ende dieses Vorgangs wird durch einen längeren, höheren Ton angezeigt.

ZynVoice lässt sich über einen Eintrag im Admin-Menü konfigurieren. Zu den Einstellungen gehören:

  • ZynVoice aktivieren
  • Stimme
  • Geschwindigkeit
  • Lautstärke
  • Soundkartenausgang

Drücken Sie die ALT-Taste kräftig, um die Hilfeansicht aufzurufen. ZynVoice beginnt, die Hilfeinformationen zur aktuellen Ansicht vorzulesen. Regler 3 steuert die Hilfefunktion. Durch Drücken von Regler 3 wird die Wiedergabe angehalten oder fortgesetzt; beim Fortsetzen beginnt die Wiedergabe am Anfang des aktuellen Satzes. Durch Drehen von Regler 3 wählen Sie den vorherigen oder nächsten Satz aus. Wenn Sie Regler 3 kräftig drücken, werden die Funktionen der Regler in dieser Ansicht angesagt, einschließlich ihrer Funktionen beim Drehen, Drücken und kräftigen Drücken. Mit der Navigator-Taste können Sie die Wiedergabe stoppen oder am Anfang der Seite erneut starten. Drücken Sie Regler 4, um den Hyperlink-Modus ein- oder auszuschalten. Drehen Sie Regler 4, um einen Link auszuwählen, und drücken Sie anschließend Regler 4, um dem Link zu folgen. Drücken Sie BACK, um den Link-Modus zu beenden. Der erste Link auf jeder Seite führt zu einem Verzeichnis aller verfügbaren Hilfeseiten. Gibt es auf der Seite keine weiteren Links, wird durch Drücken von Regler 4 direkt das Verzeichnis aufgerufen.

Einige Ansichten enthalten Optionslisten, deren Einträge zusätzliche Informationen bieten. Standardmäßig wird nur der Titel des Listeneintrags angesagt. Durch Drücken der ZynVoice-Taste können Sie diese zusätzlichen Informationen vorlesen lassen. Für diese Ansichten gibt es möglicherweise keine eigenen Hilfeseiten, da sie weitgehend selbsterklärend sind.

Wenn eine Aktion bestätigt werden muss, wird die Bestätigungsaufforderung angesagt. Sie können die Aktion dann mit den Tasten SELECT oder BACK bestätigen beziehungsweise abbrechen. Nur bei einer Bestätigung wird ein kurzer Ton ausgegeben.
