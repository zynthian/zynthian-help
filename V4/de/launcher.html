Launcher-Ansicht

Der Launcher ist die Hauptansicht des Sequencers. Sie können jederzeit zum Launcher wechseln, indem Sie Knob 1 (BACK) wiederholt kurz drücken, bis Sie ihn erreichen.

Vom Mixer aus können Sie durch Drücken von BACK zum Launcher wechseln. Vom Launcher aus gelangen Sie durch Drücken von BACK zum Mixer. Launcher und Mixer sind tatsächlich eine einzige Ansicht mit zwei Modi.

Bitte beachten Sie, dass die zusätzlichen Tasten von V4 neu zugewiesen wurden, damit bestimmte Funktionen wie das Kopieren/Einfügen aus der Zwischenablage und das Verschieben von Spalten einfacher zugänglich sind.

Der Launcher ist ein Raster, dessen Spalten den chains (Mixer-Kanälen) entsprechen. Die Zeilen werden „Phrasen“ genannt und sind den „Scenes“ in Ableton Live recht ähnlich. Zellen können Sequencer-Patterns oder Audio-Clips enthalten. Eine Ausnahme ist die Hauptspalte, die Phrase-Launcher enthält.

Anfangs ist das Raster leer und zeigt nur den Hauptkanal. Wenn Sie einen chain hinzufügen, wird dem Raster eine neue Spalte hinzugefügt. Wenn Sie einen chain löschen, wird die zugehörige Spalte aus dem Raster entfernt. Beachten Sie, dass die zugehörigen Patterns nicht gelöscht werden. Sie sind dem MIDI-Kanal zugeordnet. Wenn Sie einen neuen chain mit demselben MIDI-Kanal erstellen, sind die entfernten Patterns wieder verfügbar.

Zellauswahl

Der Cursor ist ein gelber Rahmen, der die ausgewählte Zelle hervorhebt. Sie können den Cursor durch Drehen von Knob 3 und 4 bewegen:

  • Knob 2 => Vertikal bewegen => Phrase auswählen
  • Knob 4 => Horizontal bewegen => chain auswählen

chains hinzufügen

Um einen neuen chain zu erstellen, drücken Sie S3 kurz. Sie können auch das Hauptmenü verwenden (BACK lang drücken).

chain-Auswahl

Der aktive chain ist daran zu erkennen, dass die Legende am unteren Rand des Kanals rot hervorgehoben ist. Sie können den aktiven chain ändern, indem Sie Knob 4 drehen. Ein dünner Streifen am unteren Rand der Legende zeigt an, dass der chain für MIDI-Eingaben aktiv ist.

chains verschieben

Sie können Ihre Spalten (chains) neu anordnen, indem Sie einen beliebigen chain horizontal an die gewünschte Position verschieben. Sie können die gewünschten chains auch rechts andocken, direkt neben dem Haupt-chain:

  • S3 lang drücken, um den ausgewählten chain zu verschieben. In der chain-Legende wird ein Doppelpfeil angezeigt.
  • Knob 4 drehen, um den chain an die gewünschte Position zu verschieben. Um einen chain rechts anzudocken, verschieben Sie ihn einfach weiter nach rechts.
  • SELECT oder BACK kurz drücken, um den Vorgang abzuschließen.

Beachten Sie, dass Sie Ihre chains auch in der Mixer-Ansicht auf diese Weise verschieben können.

Patterns und Audio-Clips kopieren/einfügen

Verwenden Sie zum Kopieren und Einfügen von Patterns oder Audio-Clips die Puffertasten S1/S2 wie folgt:

  • S1 oder S2 lang drücken, um den Inhalt der ausgewählten Zelle in den Puffer zu kopieren. Es gibt keine visuelle Rückmeldung.
  • Knob 2 und 4 drehen, um den Cursor an die gewünschte Position zu bewegen. Beachten Sie, dass Sie beispielsweise kein Sequencer-Pattern in eine Audio-Clip-Zelle einfügen können.
  • S1/S2 kurz drücken, um den Inhalt einzufügen. Sie können den Inhalt des Puffers beliebig oft einfügen. Ist die Zielzelle nicht leer, werden Sie um eine Bestätigung gebeten.

Phrase-Optionen

Im Menü „Phrase-Optionen“ können Sie Parameter konfigurieren und Phrasen verwalten.

Die Phrase-Parameter sind:

  • Dauer: Anzahl der Takte. Standardmäßig wird der Wert der längsten Sequenz in der Zeile verwendet.
  • Tempo: Beim Starten der Phrase wird das Tempo auf den angegebenen BPM-Wert geändert.
  • Beats per Bar: Die in den Patterns verwendete Taktart.
  • Automatisieren: Mit den Optionen „Loop from“, „loops to play“ und „jump to“ können Sie einfache Songstrukturen erstellen.

Die Optionen zur Phrasenverwaltung sind:

  • Phrase einfügen: Eine neue Phrase (Zeile) in den Launcher einfügen.
  • Phrase klonen: Die ausgewählte Phrase (Zeile) klonen.
  • Phrase verschieben: Die ausgewählte Phrase (Zeile) an eine neue Position verschieben.
  • Phrase löschen: Die ausgewählte Phrase (Zeile) löschen.

Beim Verwalten von Phrasen müssen Sie möglicherweise die Automatisierungsparameter der betroffenen Phrasen anpassen.
