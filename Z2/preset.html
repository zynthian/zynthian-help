Preset View

The preset view allows managing presets for the processor. To access the preset view for the active processor:

  • From the chain-control or chain-config views, short press CTRL button. Note CTRL button color changes from green to orange.
  • From any other view, bold press CTRL button. Note CTRL button color changes from blue to orange.

Note the active processor is the highlighted processor in the active chain.

Once in the preset view, you can:

  • Rotate knob-4 or use the UP/DOWN arrow buttons to browse the list. If preset preload is enabled (see admin view), the highlighted preset will be preloaded when moving across the list.
  • Short press knob-4 or SELECT button to select a preset for the processor.
  • Bold press knob-4 or SELECT button to open the preset options.
  • Short press CTRL button to access the bank list. Short press CTRL again to exit bank/preset selection.
  • Short press BACK button to exit bank/preset selection.

Preset options can vary depending of the processor. These are the typical preset options:

  • [ ] Favorite => Check to add the prset to the favorite list.
  • Save as new preset => Save current parameter adjustments as a new preset.
  • Delete preset => Delete preset. Only available for user presets.
  • Scan for new presets => e.g. when you install/create presets from webconf.
