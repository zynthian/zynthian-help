Vista de tempo

La vista de tempo permite controlar la base de tiempos de zynthian, que se utiliza para la secuenciación, los arpeggiators, etc.

Gire el mando 1 para ajustar el valor de BPM entre 10 y 420 BPM. Pulse y gire para ajustar en incrementos de 0,1 BPM. Tenga en cuenta que el tempo en BPM se puede automatizar mediante launcher phrases. Este control solo está disponible cuando se utiliza el reloj interno.

Gire el mando 2 para ajustar el modo del metrónomo, que configura el metrónomo de zynthian. Tiene estos valores:

  • OFF: El metrónomo está desactivado.
  • AUTO: El metrónomo suena cuando se está reproduciendo una secuencia y se detiene al final del compás después de que se detenga la última secuencia.
  • ON: El metrónomo suena continuamente.
  • INTRO: El metrónomo suena hasta que se inicia una secuencia. Puede usar esta opción como cuenta de entrada cuando no quiera o no necesite que el metrónomo suene durante la interpretación.
  • NO ACCENT: El metrónomo suena continuamente, pero sin acentuar el primer tiempo de cada compás. Funciona más como un metrónomo tradicional, que se utiliza exclusivamente para marcar el tempo y no la base de tiempos.
  • SILENT: El metrónomo funciona, pero no produce ningún sonido. Esto puede resultar útil para que el transporte funcione cuando no hay secuencias en reproducción. Algunos plugins pueden beneficiarse de ello.

Gire el mando 3 para ajustar el nivel de volumen del metrónomo.

Nota: El sonido del clic del metrónomo se envía a la cadena principal mediante su envío auxiliar de mezcla, que permite controlar individualmente el nivel, el balance, etc. El reproductor de audio global comparte esta mezcla auxiliar.

Gire el mando 4 para cambiar el compás (tiempos por compás). Los cambios de compás se aplican al comienzo del siguiente compás.

Nota: El tempo (BPM) y el compás (tiempos por compás) se pueden automatizar mediante launcher phrases.

Reloj externo

Si se utiliza un reloj externo, el control de BPM se sustituye por el divisor de reloj. El valor predeterminado del divisor de reloj es 24 PPQN, que es el valor que utiliza MIDI clock, pero se puede ajustar para admitir otras velocidades de reloj externo en el rango de 1 a 48 PPQN.

El reloj interno funciona a 1920 PPQN y utiliza un bucle de enganche de fase (PLL) para obtener este reloj de alta resolución a partir del reloj de entrada lento. Para utilizar un reloj externo, seleccione «MIDI Clock Source» para una entrada MIDI en la vista Entrada MIDI.

Tap-Tempo

Hay una pantalla grande con el valor de BPM que puede tocar para establecer el tempo. También puede tocar el botón de tempo para establecerlo.
