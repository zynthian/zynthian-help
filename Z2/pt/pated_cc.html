Editor de CC do pattern

O editor de CC do pattern permite automatizar alterações de parâmetros adicionando eventos MIDI CC aos patterns do sequenciador. O menu contextual (OPT) permite modificar os parâmetros do pattern e as opções de edição.

Os botões PLAY/STOP podem ser utilizados para reproduzir/parar o pattern. O botão REC ativa a gravação em tempo real de MIDI CC durante a reprodução.

O modo ALT permite aceder a funcionalidades especiais, como anular/refazer e copiar/colar patterns.

A gravação em tempo real, a função anular/refazer e a cópia/colagem de patterns também são suportadas pelo editor de CC e funcionam de forma muito semelhante ao editor de notas.

Funcionamento básico

Para cada pattern, pode automatizar até 127 parâmetros, utilizando os 127 números de CC disponíveis.

Antes de poder automatizar qualquer parâmetro, tem de atribuir os parâmetros que pretende automatizar aos números de CC que pretende utilizar. Existem 2 formas de o fazer:

  • Utilize MIDI-learning para atribuir parâmetros do engine a números de CC. Para tal, precisa de um controlador MIDI com knobs ou faders.
  • No menu de opções do parâmetro do engine, selecione ZynStep CC para atribuir manualmente um número de CC.

Depois de atribuir o parâmetro que pretende automatizar, siga estes passos no editor de CC para criar manualmente o seu pattern de CC:

  • Rode o knob 1 para selecionar o número de CC que pretende editar. Se o CC já estiver atribuído, verá o nome do parâmetro.
  • Rode o knob 4 para deslocar o cursor ao longo do eixo temporal do pattern.
  • Prima brevemente o knob 4 para adicionar/remover um ponto da curva.
  • Rode o knob 3 para deslocar o ponto (valor de CC) para cima e para baixo.
  • Prima brevemente o knob 1 para voltar ao editor de notas.

Pode utilizar o dedo para desenhar a curva e deslocar os pontos para cima e para baixo. Também pode gravar em tempo real (REC + PLAY) e mover o knob atribuído no seu controlador MIDI.

Durante a reprodução, os valores de CC são interpolados a cada clock tick (1920 ticks por semínima). A interpolação de CC está ativada por predefinição, exceto para pedais (por exemplo, CC64).

No menu de opções do pattern, pode ativar ou desativar a interpolação de CC para cada número de CC individualmente, limpar o pattern de CC mantendo as notas e muito mais.

Naturalmente, pode editar e ajustar parâmetros durante a reprodução do pattern, para ouvir imediatamente o resultado enquanto modifica os valores de CC em tempo real.

Gravar patterns

Prima o botão REC para ativar a gravação MIDI. Enquanto a gravação estiver armada, o botão REC acende-se a vermelho.

Captura passo a passo

Não é suportada para eventos CC.

Captura em tempo real

Se o pattern estiver a ser reproduzido, os eventos de notas e CC serão capturados em tempo real. São gravados no momento exato em que são capturados, sem quantização. Se desejar, pode aplicar quantização à reprodução (consulte o menu de opções do pattern). Durante a captura em tempo real, o histórico é guardado em cada ciclo do pattern, apenas se tiverem sido capturadas notas novas.

Anular/Refazer

No modo ALT, pode utilizar as teclas de seta para anular/refazer:

  • LEFT: Anular a última operação de edição.
  • RIGHT: Refazer a última operação anulada.
  • DOWN: Anular TUDO.
  • UP:Refazer TUDO.

Existe um método alternativo para anular/refazer, que pode ser utilizado por conveniência ou quando não for fácil aceder ao modo ALT:

  • com a gravação armada (botão REC aceso a vermelho)...
  • Prima com pressão prolongada o botão BACK para entrar no modo de navegação do histórico.
  • Rode o knob 4 para percorrer o histórico.
  • Prima BACK para sair.

Tenha em atenção que, embora o número de passos do histórico seja ilimitado, o histórico não é guardado no estado e perde-se quando voltar a carregar o snapshot. Os snapshots guardam apenas o último estado.

Opções do pattern

Prima brevemente ALT para abrir o menu de opções do pattern, que permite modificar as propriedades do pattern, bem como várias opções de edição. Estes são os parâmetros do pattern:

  • Rename: Altera o nome da sequência apresentado nos pads do launcher.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: O número de program-change acionado com o pattern. Pode ser utilizado para alterar ZS3, etc.
  • Length: A duração do pattern em compassos e tempos.
  • Steps/Beat: O número de steps por tempo. O step é a menor unidade temporal da grelha do pattern, mas a posição e a duração dos eventos podem ser ajustadas em frações de step.
  • Quantization: A quantização pode estar DISABLED ou definida como 1, 1/2, 1/3, 1/4 ou 1/6 de step.
  • Swing Amount: A quantidade de swing em %.
  • Swing Divisor: O número de divisões utilizado para o swing. Utilize 1 com 30% para obter um swing ternário perfeito.
  • Time Humanization: Aleatoriza o tempo das notas segundo uma distribuição gaussiana, para simular imprecisão humana.
  • Interpolate CC## values: Ativa ou desativa a interpolação dos valores de CC para o número de CC selecionado.

Opções de edição

  • Copy this to clipboard: Copia o pattern para a área de transferência.
  • Paste from clipboard: Cola o conteúdo da área de transferência no pattern atual.
  • Load pattern: Carrega um pattern de um ficheiro.
  • Save pattern: Guarda o pattern num ficheiro.
  • Import from SMF: Carrega um pattern de um Standard MIDI File (.mid)
  • Export to SMF: Guarda o pattern num Standard MIDI File (.mid)
  • Clear pattern ALL: Elimina todas as notas e eventos CC do pattern.
  • Clear pattern CC##: Elimina do pattern todos os eventos CC do número de CC selecionado.
