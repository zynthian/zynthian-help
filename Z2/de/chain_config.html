Chain-Konfigurationsansicht

In der Chain-Konfigurationsansicht, auch Auswahlmodus genannt, können Sie alle Aspekte einer chain konfigurieren.

Das linke Seitenfenster enthält die Liste der Blöcke, aus denen Ihre chain besteht, einschließlich der Processor. Das rechte Fenster zeigt eine reduzierte Version der Chain-Steuerungsansicht. Verwenden Sie Regler 3, um die chain-Blöcke auf der linken Seite zu durchsuchen, und Regler 4, um die Liste auf der rechten Seite zu durchsuchen.

Um die Ansicht zu verlassen, drücken Sie kurz BACK. Dadurch kehren Sie zur Chain-Steuerungsansicht zurück.

Die chain-Blöcke im linken Fenster funktionieren ähnlich wie in der Chain-Manager-Ansicht und hängen vom chain-Typ und den Processor ab. Sie können Folgendes umfassen:

  • Chain-Optionen
  • MIDI-Eingang
  • Audio-Eingang
  • MIDI-Processor
  • Synth-Processor
  • Audio-Processor
  • MIDI-Ausgang
  • Audio-Ausgang

Processor-Blöcke

Wenn ein Processor ausgewählt ist, wird die rechte Liste so verschoben, dass die Parameterseiten dieses Processor angezeigt werden. Sie können die Processor-Optionen mit kurzem Druck auf Regler 3, kurzem Druck auf OPT oder durch ein zweites kurzes Tippen auf den Block auf einem Touchscreen aufrufen.

Blöcke ohne Processor

Wenn ein Block ohne Processor ausgewählt ist, z. B. Chain-Optionen, MIDI-Eingang usw., wird im rechten Fenster ein Konfigurationsbereich angezeigt. Navigieren Sie mit Regler 4 drehen durch die Optionen und wählen bzw. aktivieren Sie Optionen mit kurzem Druck auf Regler 4. Alternativ können Sie die Tasten UP/DOWN und SELECT verwenden. Wenn eine Option Unteroptionen hat, rufen Sie das Unteroptionsmenü mit langem Druck auf Regler 4, langem Druck auf SELECT oder kurzem Druck auf OPT auf.
