L’interface utilisateur

L’interface utilisateur du zynthian V4 se commande principalement à l’aide des éléments suivants :

  • 4 boutons rotatifs avec poussoir
  • 4 boutons (S1-S4)
  • écran tactile résistif

Il est également possible de commander l’interface utilisateur du zynthian :

  • à l’aide de l’interface VNC
  • avec un contrôleur MIDI compatible
  • avec des notes MIDI sur le canal MIDI maître
  • avec un clavier d’ordinateur (raccourcis clavier)
  • à l’aide d’OSC CUIA

Ce guide couvre uniquement l’interface utilisateur principale, qui se commande avec les boutons rotatifs, les boutons et les interactions tactiles. Pour les autres méthodes, veuillez consulter le wiki zynthian.

Actions des boutons rotatifs

Il existe cinq actions possibles avec les boutons rotatifs :

  • Pression courte : une pression de moins de 0,3 seconde déclenche l’action de pression courte(*).
  • Pression appuyée : une pression de plus de 0,3 seconde et de moins de 2 secondes déclenche l’action de pression appuyée(*).
  • Pression longue : une pression maintenue pendant plus de 2 secondes déclenche l’action de pression longue(*).
  • Rotation : la rotation d’un bouton peut modifier la valeur d’un paramètre, changer l’élément sélectionné dans une liste ou déplacer le curseur horizontalement ou verticalement. L’accélération du bouton permet un réglage plus précis à faible vitesse de rotation et plus grossier à vitesse élevée.
  • Pression + rotation : la rotation d’un bouton tout en le maintenant enfoncé peut augmenter la résolution et permettre un réglage précis.

Actions des boutons

Il existe trois actions possibles avec les boutons :

  • Pression courte : une pression de moins de 0,3 seconde déclenche l’action de pression courte (*).
  • Pression appuyée : une pression de plus de 0,3 seconde et de moins de 2 secondes déclenche l’action de pression appuyée(*).
  • Pression longue : une pression maintenue pendant plus de 2 secondes déclenche l’action de pression longue(*).

(*) La durée des actions de pression peut être configurée dans l’outil webconf, sous l’onglet des options avancées de l’interface utilisateur.

Notez que tous les boutons rotatifs et boutons ne sont pas associés à une fonction pour chaque type d’action. Leur fonction peut varier selon le contexte. Les pages d’aide consacrées aux différentes vues décrivent ces fonctions en détail. Repérez les icônes d’action présentées ci-dessus, car elles seront utilisées dans ce guide.

Utilisation des boutons rotatifs

Les boutons rotatifs du V4 constituent le principal moyen de naviguer dans l’interface utilisateur. Leur fonction dépend du contexte, en particulier pour les actions de rotation, de pression courte et de pression appuyée. Les actions de pression longue sont toujours globales. Les boutons sont numérotés de haut en bas et de gauche à droite. Les noms imprimés sur le boîtier en aluminium du V4 correspondent donc aux boutons suivants :

  • layer => bouton n° 1
  • back => bouton n° 2
  • learn/shot => bouton n° 3
  • select => bouton n° 4

Dans ce guide, les noms et les numéros des boutons sont utilisés indifféremment.

Règle générale

Bien que le comportement des boutons dépende du contexte, un modèle peut servir de règle générale et s’applique à de nombreuses vues :

Bouton SELECT

  • Dans les vues de sélection (listes) :
    • Tournez le bouton pour parcourir la liste.
    • Effectuez une pression courte pour sélectionner des éléments.
    • Effectuez une pression appuyée pour ouvrir les options contextuelles.
  • Dans les vues en grille, il s’agit du bouton de l’axe X. Tournez le bouton pour déplacer le curseur horizontalement.
  • Dans les vues fractionnées comportant 2 listes déroulantes, il contrôle la liste de droite.

Bouton BACK

  • Effectuez une pression courte pour revenir à la vue précédente.
  • Dans les vues en grille, il s’agit du bouton de l’axe Y. Tournez le bouton pour déplacer le curseur verticalement.

Bouton LEARN/SHOT

  • Dans les vues fractionnées comportant 2 listes déroulantes, il contrôle la liste de gauche.
    • Tournez le bouton pour parcourir la liste de gauche.
    • Effectuez une pression courte pour sélectionner un élément dans la liste de gauche.
Cette règle générale sera complétée dans la section suivante.
Le volume principal est toujours accessible en un clic. Effectuez une pression appuyée sur le bouton BACK pour ouvrir la vue de la table de mixage, puis tournez le bouton Learn/Shot pour modifier le volume principal.

Utilisation des boutons-poussoirs

Le fonctionnement classique du zynthian (V1-V4) repose sur les poussoirs des 4 boutons rotatifs. Les actions de pression courte dépendent généralement du contexte, tandis que les actions de pression appuyée et longue sont généralement globales.

Dans les sections ci-dessous, sauf indication contraire, les actions par défaut des poussoirs sont les suivantes :

  • LAYER
    • pression courte : dépend du contexte.
    • pression appuyée : ouvre le gestionnaire de chain.
    • pression longue : ouvre l’aide.
  • BACK
    • pression courte : revient à la vue précédente. Bascule entre les vues de la table de mixage et du launcher.
    • pression appuyée> : ouvre le menu principal.
    • pression longue : ouvre le menu d’extinction.
  • LEARN/SHOT
    • pression courte : dépend du contexte.
    • pression appuyée : ouvre la liste ZS3.
    • pression longue : ouvre la liste des snapshots.
  • SELECT
    • pression courte : sélectionne ou coche/décoche l’élément sélectionné.
    • pression appuyée : affiche les options de l’élément sélectionné. Dépend du contexte.
    • pression longue : déclenche le PANIC ! Arrête toutes les notes et tous les sons.

Aide contextuelle

Effectuez une pression longue sur le bouton LAYER pour ouvrir l’aide contextuelle de la vue actuelle. Depuis l’écran d’aide, vous pouvez :

  • Tourner le bouton 4 ou appuyer sur les boutons S3/S4 pour faire défiler le contenu.
  • Effectuer une pression courte sur le bouton 4 pour parcourir les liens.
  • Effectuer une pression courte sur BACK pour revenir à la page précédente ou quitter l’écran d’aide.

Les boutons supplémentaires du V4

Les boutons-poussoirs supplémentaires en silicone du V4 (S1-S4) peuvent être configurés selon les préférences de l’utilisateur. Pour cela, utilisez l’outil webconf et accédez aux options avancées de la section de configuration du câblage. Vous y trouverez plusieurs profils de personnalisation prédéfinis :

V4 Studio

Les 4 boutons-poussoirs en silicone sont associés comme suit :

  • S1
    • pression courte => enregistreur/lecteur audio
    • pression appuyée> => enregistreur/lecteur MIDI
    • pression longue> => couper tous les sons (PANIC !)
  • S2
    • pression courte => Launcher
    • pression appuyée => éditeur de patterns
    • pression longue => couper tous les sons (PANIC !)
  • S3
    • pression courte/appuyée => flèche vers le haut
    • pression longue => couper tous les sons (PANIC !)
  • S4
    • pression courte/appuyée => flèche vers le bas
    • pression longue => bascule l’interface TTS (Text-To-Speech).

V4 Stage

Les 4 boutons-poussoirs en silicone sont associés aux program-change MIDI 1-4. Ce profil est spécialement conçu pour une utilisation avec ZS3.

  • S1 => programme MIDI 1
  • S2 => programme MIDI 2
  • S3 => programme MIDI 3
  • S4 => programme MIDI 4

V4 CC Switches

Les 4 boutons-poussoirs en silicone sont associés aux MIDI CC 47-50. Ce profil est spécialement conçu pour le MIDI-learn des paramètres à bascule (par exemple, avec SooperLooper).

  • S1 => bascule CC 47 (valeur 0/127)
  • S2 => bascule CC 48 (valeur 0/127)
  • S3 => bascule CC 49 (valeur 0/127)
  • S4 => bascule CC 50 (valeur 0/127)

La barre supérieure

En haut de l’écran se trouve généralement une barre contenant des informations. Elle peut ne pas s’afficher dans certaines vues, par exemple dans les fenêtres de confirmation ou d’information. La barre supérieure se compose de 2 zones :

La barre de titre

La barre de titre sert de fil d’Ariane. Elle affiche généralement le titre de la vue ou des informations sur le snapshot, le zs3 ou la chain actuel(le) (canal MIDI, moteur, banque et preset).

La zone d’état

Dans le coin supérieur droit, à côté de la barre de titre, une zone affiche en temps réel des informations utiles :

  • Crête-mètre audio numérique (DPM) : barres horizontales animées indiquant le niveau audio numérique et les crêtes.
  • Icônes d’état : indication de différents états du zynthian.

Le crête-mètre audio numérique (DPM)

Le DPM couvre la plage de -50dBFS à 0dBFS, c’est-à-dire du niveau maximal admissible à pleine échelle (tout à droite) jusqu’à 50dB en dessous (tout à gauche) :

  • Le segment vert couvre la plage de -50dBFS à -10dBFS.
  • Le segment jaune couvre la plage de -10dBFS à -3dBFS.
  • Le segment rouge couvre la plage de -3dBFS à 0dBFS.

Les canaux gauche et droit disposent de crête-mètres indépendants, qui mesurent la sortie du système, c’est-à-dire le mixage audio envoyé à la sortie du Zynthian. Le niveau décroît selon une loi logarithmique : il faut une seconde pour atteindre -200dBFS, et environ un quart de seconde pour atteindre -50dBFS (limite inférieure de la plage affichée). Les crêtes s’affichent instantanément, c’est-à-dire que le temps d’attaque du crête-mètre est immédiat (*). La barre de maintien des crêtes reste affichée pendant deux secondes ou jusqu’à ce qu’une crête supérieure soit atteinte.

Ce crête-mètre est identique au DPM du mixbus principal, toujours visible dans la vue de la table de mixage. Il est donc masqué lorsque la vue de la table de mixage audio est affichée.

(*) Le DPM est actualisé 5 fois par seconde. L’affichage d’une crête peut donc être retardé de 200 ms.

Les icônes d’état


État et charge
♥ Charge CPU Cœur indiquant la charge CPU. Il s’affiche en vert lorsque la charge est inférieure à 50 %, en jaune lorsqu’elle dépasse 50 % et en rouge au-delà de 75 %.
↺ Mise à jour logicielle disponible Lorsqu’une mise à jour logicielle est disponible, le symbole vert de recyclage s’affiche. Vous pouvez effectuer la mise à jour depuis le menu d’administration, webconf ou le terminal.
⚠ XRun Cette icône s’affiche en cas de XRuns. Ceux-ci peuvent s’accompagner de clics et de craquements dans la sortie audio. Cela signifie que le CPU ne parvient pas à traiter ou transférer l’audio assez rapidement. Vous devriez envisager de désactiver certaines options gourmandes en ressources CPU (comme VNC, le casque, etc.) ou de réduire la complexité de vos chains.
⚡︎ Sous-tension Le Zynthian fonctionne en mode dégradé, la fréquence du CPU étant limitée à 600-800 MHz afin de stabiliser le système et d’éviter un plantage. Cette icône ne devrait pas s’afficher. Si c’est le cas, envisagez d’utiliser une meilleure source d’alimentation.
🌡 Surchauffe Le Zynthian fonctionne en mode dégradé, la fréquence du CPU étant limitée à 600-800 MHz afin de stabiliser le système et d’éviter un plantage. Cette icône ne devrait pas s’afficher. Si c’est le cas, améliorez la dissipation thermique (en utilisant un dissipateur thermique, etc.).
