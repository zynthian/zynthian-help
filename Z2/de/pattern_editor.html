Pattern-Note-Editor

Mit dem Pattern-Note-Editor können Sie Notes zu einem Pattern hinzufügen oder daraus entfernen, Note-Parameter ändern, Blöcke kopieren/einfügen usw. Über das Kontextmenü (OPT) können Sie die Pattern-Parameter ändern und Bearbeitungsoptionen aufrufen.

Mit den PLAY/STOP-Tasten können Sie das Pattern wiedergeben/anhalten. Die REC-Taste aktiviert die MIDI-Aufnahme, die schrittweise oder als Live-Aufnahme (in Echtzeit) erfolgen kann.

Im ALT-Modus können Sie auf Sonderfunktionen wie Rückgängigmachen/Wiederherstellen, Blockoperationen und das Kopieren/Einfügen von Patterns zugreifen.

Grundlegende Bedienung

  • Drehen Sie die Regler 3 und 4, um den Cursor vertikal oder horizontal zu bewegen. Bei deaktiviertem ALT-Modus können Sie dafür auch die Pfeiltasten verwenden.
  • Drücken Sie Regler 4 kurz, um Notes hinzuzufügen oder zu entfernen. Drücken Sie Regler 4 fest, um Note-Parameter zu bearbeiten. Sie können dafür auch die SEL-Taste verwenden.
  • Drehen Sie Regler 2, um die Zoomstufe anzupassen. Drücken Sie Regler 2 kurz, um den Zoom auf den Standardwert zurückzusetzen.
  • Drücken Sie Regler 3 kurz, um die Blockauswahl aufzurufen. Der Ablauf für Blockoperationen wird im folgenden Abschnitt ausführlich erklärt.
  • Drücken Sie die OPT-Taste kurz, um das Menü mit den Pattern-Optionen zu öffnen. Dort können Sie alle Pattern-Parameter ändern. Drücken Sie Regler 2 fest, um direkt die Pattern-Länge zu ändern.
  • Drücken Sie Regler 1 kurz, um zwischen dem Note-Editor und dem CC editor zu wechseln.

Patterns aufnehmen

Drücken Sie die REC-Taste, um die MIDI-Aufnahme zu aktivieren. Wenn die Aufnahme scharfgeschaltet ist, leuchtet die REC-Taste rot.

Schrittweise Aufnahme

Wird das Pattern nicht wiedergegeben, werden Note-Ereignisse an der Cursorposition aufgenommen und der Cursor anschließend zum nächsten Step bewegt. Mit dem Sustain-Pedal können Sie Steps überspringen.

Live-Aufnahme

Wird das Pattern wiedergegeben, werden Note- und CC-Ereignisse in Echtzeit aufgenommen. Sie werden exakt zum Aufnahmezeitpunkt und ohne Quantisierung aufgezeichnet. Bei Bedarf können Sie bei der Wiedergabe eine Quantisierung anwenden (siehe Menü mit den Pattern-Optionen). Während der Live-Aufnahme wird bei jedem Pattern-Durchlauf ein Verlauf gespeichert, jedoch nur, wenn neue Notes aufgenommen wurden.

Rückgängigmachen/Wiederherstellen

Im ALT-Modus können Sie mit den Pfeiltasten Änderungen rückgängig machen oder wiederherstellen:

  • LINKS: Letzten Bearbeitungsschritt rückgängig machen.
  • RECHTS: Letzten rückgängig gemachten Schritt wiederherstellen.
  • UNTEN: ALLES rückgängig machen.
  • OBEN: ALLES wiederherstellen.

Alternativ können Sie Änderungen wie folgt rückgängig machen oder wiederherstellen. Dieser Ablauf ist praktisch, wenn der ALT-Modus nicht ohne Weiteres verfügbar ist:

  • Wenn die Aufnahme scharfgeschaltet ist (REC-Taste leuchtet rot) ...
  • Drücken Sie die BACK-Taste fest, um den Verlaufsnavigationsmodus aufzurufen.
  • Drehen Sie Regler 4, um den Verlauf zu durchlaufen.
  • Drücken Sie BACK, um den Modus zu verlassen.

Die Anzahl der Verlaufsschritte ist zwar unbegrenzt, der Verlauf wird jedoch nicht im Zustand gespeichert und geht verloren, wenn Sie den snapshot erneut laden. Snapshots speichern nur den jeweils letzten Zustand.

Note-Parameter

Sie können jede Note im Pattern bearbeiten, indem Sie den Cursor darauf positionieren und sie durch festes Drücken auswählen:

  • Drücken Sie Regler 4 fest oder SELECT fest, um den Parameter-Editor für die ausgewählte Note aufzurufen.
  • Drehen Sie Regler 4 oder verwenden Sie die LINKS-/RECHTS-Tasten, um den Parameter auszuwählen.
  • Drehen Sie Regler 3 oder verwenden Sie die OBEN-/UNTEN-Tasten, um den Wert des ausgewählten Parameters zu ändern.
  • Falls verfügbar, können Sie den Wert des ausgewählten Parameters mit Regler 2 fein einstellen.

Folgende Parameter können bearbeitet werden:

  • Duration: In Steps. Verwenden Sie Regler 2 für die Feineinstellung.
  • Velocity: MIDI-Note-Velocity von 0 bis 127.
  • Offset: Relative Verschiebung zum Start-Step der Note.
  • Stutter Speed: Anzahl der Retrigger pro Beat.
  • Stutter Velo: Verlauf der Note-Velocity während des Stutters. Mögliche Werte: FLAT, FADE-IN, FADE-OUT.
  • Stutter Ramp: Verlauf der Retrigger-Geschwindigkeit während der Notendauer. Mögliche Werte: NONE, SPEED-DOWN, SPEED-UP.
  • Play Frequency: In jedem N-ten Loop überspringen/wiedergeben.
  • Play Chance: Wiedergabewahrscheinlichkeit.
  • Stutter Frequency: In jedem N-ten Loop stuttern.
  • Stutter Chance: Stutter-Wahrscheinlichkeit.

Der Stutter-Speed-Ramp-Effekt funktioniert folgendermaßen:

  • Speed ramp-up: Erhöht die Stutter-Geschwindigkeit ausgehend vom angegebenen Wert über die Dauer der Note.
  • Speed ramp-down: Verringert die Stutter-Geschwindigkeit ausgehend von einem berechneten Wert, sodass am Ende der Notendauer die angegebene Geschwindigkeit erreicht wird.
Änderungen an Note-Parametern werden sofort und in Echtzeit übernommen. Sie können die Note-Parameter auch während der Wiedergabe des Patterns ändern. Das Ergebnis hören Sie, sobald der Wiedergabe-Cursor die bearbeitete Note erreicht.

Visuelle Rückmeldung

Die meisten Note-Parameter werden visuell dargestellt:

  • Die Dauer der Note wird durch die Länge des Rechtecks dargestellt.
  • Die Velocity der Note wird durch die Hintergrundfarbe des Rechtecks dargestellt. Je niedriger die Velocity, desto dunkler die Farbe. Je höher die Velocity, desto heller die Farbe.
  • Der Stutter einer Note wird als Folge vertikaler Balken dargestellt.
  • Die Stutter-Geschwindigkeit ist proportional zur „Balkendichte“.
  • Der Stutter-Velocity-Effekt wird durch die Wuchsrichtung der Balken dargestellt.
  • Für Stutter Speed Ramp gibt es keine visuelle Rückmeldung. Entschuldigung!
  • Weiße Beschriftungen stehen für Play Frequency oder Play Chance.
  • Violette Beschriftungen stehen für Stutter Frequency oder Stutter Chance.

Wenn Sie mehrere Chance- oder Frequency-Eigenschaften gleichzeitig anwenden, wird nur eine davon als Beschriftung angezeigt. Die Priorität ist:

  1. Play Freq
  2. Play Chance
  3. Stutter Freq
  4. Stutter Chance

Blockoperationen

Mit Blockoperationen können Sie mehrere Notes auswählen und auf alle gleichzeitig eine Operation anwenden, zum Beispiel kopieren/einfügen oder einen Note-Parameter ändern.

Blockoperationen können Sie mit den Reglern oder im ALT-Modus mit den Tasten ausführen. Wählen Sie den Ablauf, der am besten zu Ihnen passt:

  1. Drücken Sie Regler 3 kurz oder F3 kurz, um den Modus zur Blockauswahl aufzurufen.
  2. Drehen Sie Regler 3 und 4 oder verwenden Sie die Pfeiltasten, um die Auswahl anzupassen.
    1. Drücken Sie Regler 4 kurz oder SEL kurz, um die Auswahl zu kopieren.
    2. Drücken Sie Regler 3 kurz oder F3 kurz, um die Auswahl auszuschneiden.
    3. Drücken Sie Regler 4 fest oder SEL fest, um die Notes auszuwählen und den MULTI-Bearbeitungsmodus aufzurufen.
  3. Drehen Sie Regler 3 und 4 oder verwenden Sie die Pfeiltasten, um den Block über das Pattern-Raster zu bewegen.
  4. Drücken Sie Regler 4 kurz oder SEL kurz, um den Block einzufügen.
  5. Wiederholen Sie die Schritte 4 und 5 beliebig oft.
  6. Drücken Sie BACK, um den Vorgang zu beenden.

Dieser Ablauf gilt für die verschiedenen Blockoperationen. Der Unterschied liegt in Schritt 2. Bei Kopieren/Ausschneiden und Einfügen ist die Auswahl grün markiert, während der MULTI-Bearbeitungsblock blau markiert ist.

Wenn Sie im ALT-Modus den Ablauf mit der F3-Taste verwenden, beachten Sie bitte, dass die Pfeiltasten im ALT-Modus normalerweise zum Navigieren im Verlauf (Rückgängigmachen/Wiederherstellen) dienen. Wenn Sie den Modus zur Blockauswahl durch Drücken von F3 aufrufen, ändert sich die Funktion der Pfeiltasten: Sie können damit die Auswahl anpassen und zum Einfügen verschieben.

MULTI-Bearbeitungsmodus

Sie können dem Ablauf unter 2.c folgen, um mehrere Notes gleichzeitig zu bearbeiten. Derzeit können nur die Parameter velocity und duration gemeinsam bearbeitet werden. Im MULTI-Bearbeitungsmodus können Sie Folgendes tun:

  • Drehen Sie Regler 4, um den gemeinsam zu bearbeitenden Parameter auszuwählen. Derzeit sind nur velocity und duration verfügbar.
  • Drehen Sie Regler 3, um den Wert des ausgewählten Parameters zu ändern. Die Werte werden schrittweise und relativ zu den ursprünglichen Werten geändert, sofern die Wertebereichsgrenzen nicht erreicht werden.
  • Drücken Sie BACK kurz, um den MULTI-Bearbeitungsmodus zu verlassen.

Wenn Sie den MULTI-Bearbeitungsmodus verlassen, bleibt der Block „ausgewählt“. Dies erkennen Sie an der bläulichen Farbe der ausgewählten Notes. Sie können weiterhin Notes hinzufügen, einzelne Notes bearbeiten usw. Die Auswahl des Blocks hat keinen Einfluss auf die normale Bedienung. Sie können den MULTI-Bearbeitungsmodus jedoch erneut aufrufen, indem Sie Regler 4 fest drücken. Drücken Sie BACK, um die Blockauswahl aufzuheben.

Drücken Sie Regler 3 fest, um alle Notes im Pattern gemeinsam zu bearbeiten.

Pattern-Optionen

Drücken Sie ALT kurz, um das Menü mit den Pattern-Optionen zu öffnen. Dort können Sie die Pattern-Eigenschaften sowie verschiedene Bearbeitungsoptionen ändern. Dies sind die Pattern-Parameter:

  • Rename: Ändert den Namen der Sequenz, der auf den Pads des Launchers angezeigt wird.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: Die Program-Change-Nummer, die mit dem Pattern ausgelöst wird. Damit können Sie beispielsweise ZS3 wechseln.
  • Length: Die Pattern-Länge in Takten und Beats.
  • Steps/Beat: Die Anzahl der Steps pro Beat. Der Step ist die kleinste Zeiteinheit im Pattern-Raster. Die Position und Dauer eines Ereignisses können jedoch auch in Step-Bruchteilen angepasst werden.
  • Quantization: Die Quantisierung kann deaktiviert oder auf 1, 1/2, 1/3, 1/4 oder 1/6 Step eingestellt werden.
  • Swing Amount: Die Stärke des Swing-Effekts in %.
  • Swing Divisor: Die Anzahl der Unterteilungen für Swing. Mit dem Wert 1 und 30 % erhalten Sie einen perfekten ternären Swing.
  • Time Humanization: Die Note-Zeit wird gemäß einer Gauß-Verteilung randomisiert, um menschliche Ungenauigkeit zu simulieren.
  • Velocity Humanization: Die Note-Velocity wird gemäß einer Gauß-Verteilung randomisiert, um menschliche Ungenauigkeit zu simulieren.
  • Note Play Chance: Die Wahrscheinlichkeit, dass Pattern-Notes wiedergegeben werden, in %. Damit können Notes zufällig ausgelassen werden.
  • Scale: Die vom Pattern-Editor verwendete Tonleiter.

  • Chord mode Ermöglicht das Hinzufügen vollständiger Akkorde anstelle einzelner Notes.
  • Transpose pattern: Transponiert das Pattern um eine bestimmte Anzahl von Halbtönen.
  • Copy this to clipboard: Kopiert das Pattern in die Zwischenablage.

  • Clear pattern notes: Löscht alle Notes aus dem Pattern.

Patterns kopieren/einfügen

Sie können vollständige Patterns kopieren/einfügen, indem Sie den ALT-Modus aufrufen. Es gibt zwei Kopier-/Einfüge-Puffer (F1 und F2). Nicht belegte Puffer leuchten orange. Belegte Puffer blinken wie folgt:

  • Blinkt grün: Der Inhalt kann durch kurzes Drücken eingefügt werden.
  • Blinkt rot: Der Inhalt kann nicht eingefügt werden. Es handelt sich um einen Audio-Clip.
  • Blinkt orange: Der Inhalt kann nicht an seiner eigenen Position eingefügt werden. Das ausgewählte Pattern ist das kopierte Pattern.

Drücken Sie F1 oder F2 fest, um das Pattern in die Zwischenablage zu kopieren. Ist der Puffer belegt, wird sein Inhalt überschrieben.

Drücken Sie F1 oder F2 kurz, während die Taste grün blinkt, um den Inhalt in das aktuelle Pattern einzufügen. Ist das aktuelle Pattern nicht leer, werden Sie zur Bestätigung aufgefordert.

Dieser Ablauf ergänzt den Kopier-/Einfüge-Ablauf des Launchers. Sie können Patterns einfügen, die Sie im Launcher kopiert haben, und das aktuelle Pattern kopieren, um es später über den Launcher einzufügen.
