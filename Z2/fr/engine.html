Vue de sélection des engines

Le sélecteur d’engine permet de parcourir et de sélectionner des engines pour le type choisi, qui peut être l’un des suivants :

  • Synthé MIDI
  • Effet audio
  • Outil MIDI
  • Générateur audio
  • Spécial

Cette vue s’affiche lorsque vous ajoutez une nouvelle chain ou que vous ajoutez/remplacez des processors dans une chain existante.

La vue est divisée en 3 colonnes :

  • [Gauche] Liste des catégories correspondant au type choisi.
  • [Centre] Liste des engines de la catégorie sélectionnée. Par défaut, seuls les engines activés sont affichés. Voir le mode avancé ci-dessous.
  • [Droite] Informations sur l’engine sélectionné, comprenant :
    • Qualité : notée de 0 à 5 étoiles.
    • Complexité : notée de 0 à 5 roues.
    • Description : un court texte décrivant les fonctionnalités de l’engine.

Vous pouvez effectuer les actions suivantes :

  • Tournez le bouton 3 ou appuyez sur les boutons GAUCHE/DROITE pour parcourir la liste des catégories.
  • Tournez le bouton 4 ou appuyez sur les boutons HAUT/BAS pour parcourir la liste des engines.
  • Appuyez sur le bouton 4 pour sélectionner l’engine mis en surbrillance et fermer le sélecteur d’engine.
  • Appuyez longuement sur le bouton 4 pour passer en mode avancé, qui affiche TOUS les engines et permet de les activer ou de les désactiver.
  • Appuyez sur le bouton 3 pour ouvrir l’écran d’informations détaillées et lire les descriptions complètes.
  • Appuyez sur RETOUR pour revenir à la vue précédente.

Vous pouvez également utiliser l’écran tactile dans les listes des catégories et des engines. Touchez la colonne des informations pour ouvrir l’écran d’informations détaillées.

Mode avancé

Pour passer en mode avancé, appuyez longuement sur le bouton 4 ou sur le bouton SEL. En mode avancé, la liste complète des engines s’affiche, y compris les engines désactivés qui sont normalement masqués. Vous pouvez cocher ou décocher les engines pour les activer ou les désactiver. Appuyez sur RETOUR pour revenir au mode normal.
