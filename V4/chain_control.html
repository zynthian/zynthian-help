Chain Control View

The chain control view provides access to the parameters of the processors in the active chain. You can:

  • Modify the value of processor parameters by rotating the knobs.
  • Enter MIDI learn mode by short pressing knob 3.

Processor parameters are grouped in pages with up to 4 parameters per page. Select pages using the S3 / S4 buttons. The list contains the control pages for all processors in the chain.

To move faster across the pages, enter select mode with short press knob 4

Note that select mode is also known as the chain config view.

MIDI Learn

You can bind any parameter to knobs, faders and CC-pads on your external MIDI controllers. There are 2 different MIDI learn modes:

  • Chain Learn: Binding is only to the selected chain. You can bind the same knob to one or several parameters in the same or different chains. Only the selected chain will react to the MIDI CC message.
  • Global Learn: The bind is global. You can bind the same knob to one or several parameters in the same or different chains. All of them will react, no matter the selected chain.
The MIDI learn procedure is:
  • short press knob 3. A ##?## indication is displayed on all parameters indicating chain learning mode. If required, press again to enter global MIDI learn. The indication will change to yellow: ??#??
  • rotate the knob associated with the parameter you want to learn. The "??#??" indication will be displayed in be displayed only on that parameter, indicating it is listening for MIDI learn.
  • move a knob/fader or tap a CC-pad on your external MIDI controller. The binding is complete and the indication now shows then MIDI channel and CC number in white.

While in MIDI learn mode, you can access the parameter control options by bold presing the knobs.

You can cancel MIDI learn at any moment by pressing back.

Parameter control options

While in MIDI learn mode, bold press any knob to access the controller options for the associated parameter. These are the common options:

  • Chain Controller: When checked, the parameter is added to the chain controller pages, at the beginning of the page list. This feature acts as a kind of "favorite parameters" for the chain.
  • X-Y Touchpad: When numeric parameters have been selected for X and Y axis, enter X-Y Touchpad mode.
  • Chain Learn: Start Chain MIDI learn for the parameter.
  • Global Learn: Start Global MIDI learn for the parameter.
  • Zynstep CC: Choose the CC number used by the sequencer to automate the parameter.
  • Unlearn: Unlearn the parameter.
  • Unlearn all controls: Unlearn all parameters in the processor.

These are the specific options for numeric controllers:

  • Absolute/Relative Mode: Allows to configure incremental knobs (encoders).
  • CC Value Range: Configure how MIDI CC values are mapped to the associated parameter.
  • X-axis: Check to use the parameter for the X axis in X-Y Touchpad mode.
  • Y-axis: Check to use the parameter for the Y axis in X-Y Touchpad mode.

These are the specific options for toggle controllers:

  • Momentary => Latch: Interprete MIDI CC pulses as toggles (latch mode).
  • Debounce: Enable debouncing to avoid spurious switches.

X-Y Touchpad

When in X-Y Touchpad mode, you can control the 2 assigned parameters at once using your finger over the touchscreen, "a la chaos-pad".
