Vue des presets

La vue des presets permet de gérer les presets du processeur. Pour accéder à la vue des presets du processeur actif :

  • Depuis les vues chain-control ou chain-config, effectuez un appui long sur le bouton 4.

Notez que le processeur actif est celui qui est mis en surbrillance dans la chain active.

Dans la vue des presets, vous pouvez :

  • Tourner le bouton 4 pour parcourir la liste. Si preset preload est activé (voir la vue admin), le preset mis en surbrillance est préchargé lors du défilement de la liste.
  • Appuyer brièvement sur le bouton 4 pour sélectionner un preset pour le processeur et fermer la vue.
  • Effectuer un appui long sur le bouton 4 pour ouvrir les options du preset.
  • Appuyer brièvement sur le bouton 2 (BACK) pour accéder à la liste des banques. Appuyez de nouveau brièvement sur BACK pour quitter la sélection de banque/preset.

Les options des presets peuvent varier selon le processeur. Voici les options courantes :

  • [ ] Favorite => Cochez cette option pour ajouter le preset à la liste des favoris.
  • Save as new preset => Enregistrer les réglages actuels des paramètres sous la forme d’un nouveau preset.
  • Delete preset => Supprimer le preset. Disponible uniquement pour les presets utilisateur.
  • Scan for new presets => Par exemple, après avoir installé ou créé des presets depuis webconf.
