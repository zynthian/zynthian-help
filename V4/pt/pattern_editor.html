Editor de notas de pattern

O editor de notas de pattern permite adicionar/remover notas num pattern, modificar parâmetros das notas, copiar/colar blocos, etc. O menu contextual (pressão curta no knob 1) permite modificar os parâmetros do pattern e as opções de edição.

Tenha em atenção que os botões extra do V4 foram reatribuídos para permitir o acesso fácil a algumas funcionalidades específicas, como copiar/colar a partir da área de transferência, operações com blocos, etc.

Funcionamento básico

  • Rode os knobs 3 e 4 para mover o cursor na vertical ou na horizontal.
  • Prima brevemente o knob 4 para adicionar/remover notas. Prima demoradamente o knob 4 para editar os parâmetros das notas.
  • Rode o knob 2 para ajustar a ampliação.
  • Prima brevemente S3 para iniciar a seleção de blocos. O fluxo de trabalho das operações com blocos é explicado em detalhe na secção abaixo.
  • Prima brevemente o knob 1 para abrir o menu de opções do pattern, que permite modificar todos os parâmetros do pattern.
  • Prima brevemente S4 para alternar entre o editor de notas e o editor de CC
    • .

Gravar patterns

Prima demoradamente o knob 3 para ativar a gravação MIDI. Quando a gravação estiver armada, o símbolo de círculo amarelo acende-se na barra de estado.

Captura passo a passo

Se o pattern não estiver a ser reproduzido, os eventos de notas serão capturados na posição do cursor, que avança para o passo seguinte. Pode utilizar o pedal de sustain para saltar passos.

Captura em tempo real

Se o pattern estiver a ser reproduzido, os eventos de notas e CC serão capturados em tempo real. São gravados no momento exato em que são capturados, sem quantização. Se pretender, pode aplicar quantização durante a reprodução (consulte o menu de opções do pattern). Durante a captura em tempo real, o histórico é guardado em cada repetição do pattern, mas apenas se tiverem sido capturadas notas novas.

Anular/refazer

Pode anular/refazer a maioria das operações de edição através do procedimento seguinte:

  • Prima demoradamente o knob 2 (BACK) para entrar no modo de navegação pelo histórico.
  • Rode o knob 4 para percorrer o histórico.
  • Prima brevemente o knob 2 (BACK) para sair.

Tenha em atenção que, embora o número de passos do histórico seja ilimitado, o histórico não é guardado no estado e perde-se quando voltar a carregar o snapshot. Os snapshots guardam apenas o último estado.

Parâmetros das notas

Pode editar cada nota do pattern colocando o cursor sobre a nota e selecionando-a com uma pressão prolongada:

  • Prima demoradamente o knob 4 ou prima demoradamente SELECT para abrir o editor de parâmetros da nota selecionada.
  • Rode o knob 4 ou utilize os botões LEFT/RIGHT para selecionar o parâmetro.
  • Rode o knob 3 ou utilize os botões UP/DOWN para alterar o valor do parâmetro selecionado.
  • Se disponível, rode o knob 2 para ajustar finamente o valor do parâmetro selecionado.

Esta é a lista de parâmetros que pode editar:

  • Duração: Em passos. Utilize o knob 2 para ajustar finamente.
  • Velocity: Velocity da nota MIDI, de 0 a 127.
  • Offset: Deslocamento relativo ao passo inicial da nota.
  • Stutter Speed: Em número de retriggers por batida.
  • Stutter Velo: Modo como a velocity da nota evolui ao longo do stutter. Pode ser: FLAT, FADE-IN, FADE-OUT
  • Stutter Ramp: Modo como a velocidade de retrigger evolui ao longo da duração da nota. Pode ser: NONE, SPEED-DOWN, SPEED-UP
  • Play Frequency: Saltar/reproduzir a cada N repetições.
  • Play Chance: Probabilidade de reprodução.
  • Stutter Frequency: Stutter a cada N repetições.
  • Stutter Chance: Probabilidade de stutter.

Quanto ao efeito de rampa de velocidade do stutter, importa explicar em detalhe como funciona:

  • Rampa de velocidade ascendente: Aumenta a velocidade do stutter a partir da velocidade especificada ao longo da duração da nota.
  • Rampa de velocidade descendente: Reduz a velocidade do stutter a partir de um valor calculado, de modo a atingir a velocidade especificada no final da duração da nota.
Ao modificar os parâmetros das notas, a alteração do valor é imediata e em tempo real. Pode modificar os parâmetros das notas durante a reprodução do pattern e ouvirá o resultado assim que o cursor de reprodução chegar à nota que está a modificar.

Indicação visual

A maioria dos parâmetros das notas tem indicação visual:

  • A duração da nota é representada pelo comprimento do retângulo.
  • A velocity da nota é representada pela cor de fundo do retângulo. Quanto menor for a velocity, mais escura será a cor. Quanto maior for a velocity, mais clara será.
  • O stutter da nota é apresentado como uma sequência de barras verticais.
  • A Stutter speed é proporcional à «densidade das barras».
  • O efeito de velocity do stutter é representado pela direção de crescimento das barras.
  • A Stutter Speed Ramp não tem indicação visual. Lamentamos!
  • As etiquetas brancas representam a frequência ou a probabilidade de reprodução.
  • As etiquetas roxas representam a frequência ou a probabilidade de stutter.

Se aplicar simultaneamente várias propriedades de probabilidade ou frequência, só verá uma delas representada como etiqueta. A prioridade das etiquetas é:

  1. Play Freq
  2. Play Chance
  3. Stutter Freq
  4. Stutter Chance

Operações com blocos

As operações com blocos permitem selecionar um conjunto de notas e executar uma operação em todas elas, como copiar/colar ou modificar um parâmetro das notas.

  1. Prima brevemente S3 para entrar no modo de seleção de blocos
  2. Rode os knobs 3 e 4 para ajustar a seleção
    1. Prima brevemente o knob 4 para copiar a seleção.
    2. Prima brevemente S3 para cortar a seleção.
    3. Prima demoradamente o knob 4 para selecionar as notas e entrar no modo de edição MULTI.
  3. Rode os knobs 3 e 4 para mover o bloco pela grelha do pattern.
  4. Prima brevemente o knob 4 para colar o bloco.
  5. Repita os passos 4 e 5 as vezes que quiser.
  6. Prima o knob 2 (BACK) para terminar.

Tenha em atenção que este fluxo de trabalho é comum às diferentes operações com blocos; o que muda é o passo 2. As operações de copiar/cortar e colar utilizam a cor verde para a seleção, enquanto o bloco de edição MULTI é apresentado a azul.

Modo de edição MULTI

Pode seguir o fluxo de trabalho 2.c para editar um conjunto de notas de uma só vez. Atualmente, só é possível editar em simultâneo os parâmetros velocity e duração. No modo de edição MULTI, pode:

  • Rodar o knob 4 para escolher o parâmetro a editar em simultâneo. Atualmente, só estão disponíveis velocity e duração.
  • Rodar o knob 3 para modificar o valor do parâmetro selecionado. Os valores são alterados incrementalmente (de forma relativa) em relação aos valores originais, exceto quando atingem os limites do intervalo.
  • Premir brevemente o knob 1 (BACK) para sair do modo de edição MULTI.

Ao sair do modo de edição MULTI, o bloco permanece «selecionado». Pode confirmar isso pela cor azulada das notas selecionadas. Embora o bloco continue selecionado, pode adicionar notas, editar notas individuais, etc., normalmente. Por conseguinte, a seleção do bloco não afeta o funcionamento normal. No entanto, pode voltar a entrar no modo de edição MULTI premindo demoradamente o knob 4. Pode anular a seleção do bloco premindo o knob 2 (BACK).

Prima demoradamente o knob 3 para editar em simultâneo todas as notas do pattern.

Opções do pattern

Prima brevemente o knob 1 para abrir o menu de opções do pattern, que permite modificar as propriedades do pattern, bem como várias opções de edição. Estes são os parâmetros do pattern:

  • Rename: Altera o nome da sequência apresentado nos pads do launcher.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: O número de program-change acionado com o pattern. Pode ser utilizado para alterar ZS3, etc.
  • Length: A duração do pattern em compassos e tempos.
  • Steps/Beat: O número de passos por tempo. O passo é a menor unidade de tempo na grelha do pattern, mas a posição e a duração dos eventos podem ser ajustadas em frações de passo.
  • Quantization: A quantização pode estar DISABLED ou definida como 1, 1/2, 1/3, 1/4 ou 1/6 de passo.
  • Swing Amount: A quantidade de swing, em %.
  • Swing Divisor: O número de divisões utilizadas para o swing. Utilize 1 com 30% para obter um swing ternário perfeito.
  • Time Humanization: Aleatoriza o tempo das notas segundo uma distribuição gaussiana para simular imprecisões humanas.
  • Velocity Humanization: Aleatoriza a velocity das notas segundo uma distribuição gaussiana para simular imprecisões humanas.
  • Note Play Chance: A probabilidade, em %, de as notas do pattern serem reproduzidas. Permite omitir notas aleatoriamente.
  • Scale: A escala utilizada pelo editor de patterns.

  • Chord mode Permite adicionar acordes completos em vez de notas individuais.
  • Transpose pattern: Transpõe o pattern um determinado número de semitons.
  • Copy this to clipboard: Copia o pattern para a área de transferência.

  • Clear pattern notes: Elimina todas as notas do pattern.

Copiar/colar patterns

Pode copiar/colar patterns completos através das opções de menu ou dos botões extra S1/S2 do V4. Existem dois buffers de copiar/colar (S1 e S2).

Prima demoradamente S1 ou S2 para copiar o pattern para a área de transferência. Se o buffer estiver ocupado, o conteúdo será substituído.

Prima brevemente S1 ou S2 para colar o conteúdo no pattern atual. Se o pattern atual não estiver vazio, ser-lhe-á pedida uma confirmação.

Este fluxo de trabalho complementa o fluxo de trabalho de copiar/colar do launcher. Pode colar patterns que tenha copiado do launcher e copiar o pattern atual para o colar posteriormente a partir do launcher.
