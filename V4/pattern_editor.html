Pattern Note Editor

The pattern note editor allows to add/remove notes in a pattern, modifying note parameters, copy/paste blocks, etc. The contextual menu (shot-push knob 1) allows modifying the pattern parameters and edit options.

Please, note that V4's extra buttons have been reassignned to allow easy access to some specific features, like copy/paste from clipboard, block operations, etc..

Basic Operation

  • Rotate knobs 3 & 4 to move the cursor vertical or horizontally.
  • Short-push knob 4 to add/remove notes. Bold-push knob 4 to edit note parameters.
  • Rotate knob 2 to adjust the zoom in and out.
  • Short-push S3 to enter block selection. The block operation workflow is explained in detail in the section below.
  • Short-push knob 1 to open the pattern options menu that allows modifying all pattern parameters.
  • Short-push S4 to toggle between the note & CC editor

Recording Patterns

Bold-push knob 3 to enable MIDI recording. While record is armed, the yellow circle symbol will light in the status bar.

Step by Step Capture

If the pattern is not playing, note events will be captured at the cursor's position, moving the cursor to the next step. You can use the sustain pedal to skip steps.

Live Capture

If the pattern is playing, note and CC events will be captured in real time. They are recorded at the exact time they are captured, without quantization. If desired, quantization can be applied to replaying (see pattern options menu). While live capturing, history is saved on each pattern loop, only if new notes were captured.

Undo/Redo

You can undo/redo most edit operations using the next procedure:

  • bold-push knob 2 (BACK) to enter history navigation mode.
  • rotate knob 4 to move along the history.
  • short push knob 2 (BACK) to end.

Note that although the number of history steps is unlimited, history is not saved in the state and will be lost when loading the snapshot again. Snapshots will save the last state only.

Note Parameters

Each note in the pattern can be edited by positioning the cursor on it and bold-selecting it:

  • Bold-push knob 4 or bold SELECT to enter the parameter editor for the selected note.
  • Rotate knob 4 or use LEFT/RIGHT buttons to select the parameter.
  • Rotate knob 3 or use UP/DOWN buttons to change the value of the selected parameter.
  • When available, rotate knob 2 to fine adjust the value of the selected parameter.

This is the list of parameters you can edit:

  • Duration: In steps. Use knob 2 to fine adjust.
  • Velocity: MIDI note velocity, from 0 to 127.
  • Offset: Relative offset respect to the note's start step.
  • Stutter Speed: In number of retriggers per beat.
  • Stutter Velo: How note velocity evolves along the stutter. It can be: FLAT, FADE-IN, FADE-OUT
  • Stutter Ramp: How retrigger speed evolves along the note duration. It can be: NONE, SPEED-DOWN, SPEED-UP
  • Play Frequency: Skip/Play every N loops.
  • Play Chance: Probability of play.
  • Stutter Frequency: Stutter every N loops.
  • Stutter Chance: Probability of stutter.

Regarding the stutter speed ramp effect, it's worth commenting how it works in detail:

  • Speed ramp-up: Increases stutter speed from the specified speed along the duration of the note.
  • Speed ramp-down: Reduces stutter speed from a calculated value to reach the specified speed at the end of the note duration.
When modifying note parameters, the value change is inmediate, in real time. You can modify note parameters while the pattern is playing and you will hear the result as soon as the playing cursor reaches the note you are modifying.

Visual Feedback

Most note parameters have some visual feedback:

  • Note's duration is represented by the rectangle's length.
  • Note's velocity is represented by rectangle's background color. Rhe lower the velocity, the darker. The higher the velocity, the lighter.
  • Note stutter is presented as a sequence of vertical bars.
  • Stutter speed is proportional to the "bar density".
  • Stutter velocity effect is represented by the bar's growing direction.
  • Stutter Speed Ramp has no visual feedback. Sorry!
  • White labels represent play frequency or chance.
  • Purple labels represent stutter frequency or chance.

If you apply several chance or freq properties simultaneously, you would only see represented one of them as label. Label priority is:

  1. Play Freq
  2. Play Chance
  3. Stutter Freq
  4. Stutter Chance

Block Operations

Block operations allow to select a set of notes and perform an operation on all of them, like copy/paste or modify a note parameter.

  1. Short push S3 to enter block select mode
  2. Rotate knob 3 & 4 to adjust the selection
    1. Short-push knob 4 to copy the selection.
    2. Short-push S3 to cut the selection.
    3. Bold-push knob 4 to select notes and enter MULTI edit mode.
  3. Rotate knob 3 & 4 to move the block across the pattern grid.
  4. Short-push knob 4 to paste the block.
  5. Repeat steps 4 & 5 as many times as you want.
  6. Push knob 2 (BACK) to end.

Note this workflow is common for the different block operations, being step 2 what makes the difference. Copy/Cut & Paste operations use green color for the selection while the MULTI edit block is colored in blue.

MULTI edit mode

You can follow 2.c workflow to edit a set of notes at once. Only velocity and duration parameters can be multi-edited at the moment. When in MULTI edit mode, you can:

  • Rotate knob 4 to choose the parameter to multi-edit. Only velocity and duration are currently available.
  • Rotate knob 3 to modify the value of the selected parameter. Values are changed incrementally (relative) to their original values, unless you reach the range limits.
  • Short push knob 1 (BACK) to exit MULTI edit mode.

When you exit MULTI edit mode, the block will remain “selected”. You know this because of the “blueish” color of the selected notes. Although the block is still selected, you can add notes, edit single notes, etc. normally. So having the block selected doesn’t affect normal operation. But you can re-enter MULTI edit mode again by bold pushing knob 4. You can un-select the block by pushing knob 2 (BACK).

Bold push knob 3 to multi-edit all notes in the pattern.

Pattern Options

Short-push knob 1 to open the pattern options menu that let you modify the pattern properties as well as a bunch of edit options. These are the pattern parameters:

  • Rename: Change the sequence's name displayed in the launcher's pads.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: The program change number that is triggered with the pattern. It can be used for changing ZS3s, etc.
  • Length: The pattern length in bars and beats.
  • Steps/Beat: The number of steps per beat. The step is the smaller unit of time in the pattern grid, but event's position and duration can be adjusted by fraction of step.
  • Quantization: Quantization can be DISABLED or set to 1, 1/2, 1/3, 1/4, 1/6 step.
  • Swing Amount: The amount of swing in %.
  • Swing Divisor: The number of divisions used for swing. Use 1 with 30% to get a perfect ternary swing.
  • Time Humanization: Randomize note's time following a gauss distribution to simulate human imprecission.
  • Velocity Humanization: Randomize note's velocity following a gauss distribution to simulate human imprecission.
  • Note Play Chance: The probability of playing pattern notes in %. This allows omitting notes ramdomly.
  • Scale: The scale used by the pattern editor.

Edit options

  • Rest note:
  • Chord mode Allows to add full chords instead of single notes.
  • Transpose pattern: Transpose the pattern by a number of semitones.
  • Copy this to clipboard: Copy the pattern to the clipboard.
  • Paste from clipboard: Paste the content of clipboard to the current pattern.
  • Load pattern: Load a pattern from file.

  • Clear pattern ALL: Delete all notes & CC events from the pattern.
  • Clear pattern notes: Delete all notes from the pattern.

Pattern Copy/Paste

You can copy/paste full patterns by using the menu options or the V4's S1/S2 extra buttons. There are two copy/paste buffers (S1 & S2).

Bold-push S1 or S2 to copy the pattern into the clipboard. If the buffer is busy, the content will be overwritten.

Short-push S1 or S2 to paste the content on the current pattern. If the current pattern is not empty, you will be asked for confirmation.

This workflow complements the launcher's copy/paste workflow. You can paste patterns you copied from the launcher and you can copy the current pattern to later be pasted from the launcher.
