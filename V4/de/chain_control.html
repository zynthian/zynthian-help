Chain-Steuerungsansicht

In der Chain-Steuerungsansicht können Sie auf die Parameter der Prozessoren in der aktiven chain zugreifen. Sie können:

  • Den Wert von Prozessorparametern ändern, indem Sie die Regler drehen.
  • Den MIDI-learn-Modus aufrufen, indem Sie Regler 3 kurz drücken.

Die Prozessorparameter sind auf Seiten mit bis zu 4 Parametern pro Seite gruppiert. Wählen Sie die Seiten über die Tasten S3 / S4 aus. Die Liste enthält die Steuerungsseiten aller Prozessoren in der chain.

Um schneller zwischen den Seiten zu wechseln, rufen Sie mit einem kurzen Druck auf Regler 4 den Auswahlmodus auf.

Beachten Sie, dass der Auswahlmodus auch als Ansicht chain config bezeichnet wird.

MIDI Learn

Sie können jeden Parameter den Reglern, Fadern und CC-Pads Ihrer externen MIDI-Controller zuweisen. Es gibt 2 verschiedene MIDI-learn-Modi:

  • Chain Learn: Die Zuweisung gilt nur für die ausgewählte chain. Sie können denselben Regler einem oder mehreren Parametern in derselben oder in verschiedenen chains zuweisen. Nur die ausgewählte chain reagiert auf die MIDI-CC-Nachricht.
  • Global Learn: Die Zuweisung gilt global. Sie können denselben Regler einem oder mehreren Parametern in derselben oder in verschiedenen chains zuweisen. Alle zugewiesenen Parameter reagieren, unabhängig davon, welche chain ausgewählt ist.
So führen Sie MIDI-learn aus:
  • Regler 3 kurz drücken. Bei allen Parametern wird die Anzeige ##?## eingeblendet, die den Chain-Learn-Modus kennzeichnet. Drücken Sie bei Bedarf erneut, um Global MIDI Learn aufzurufen. Die Anzeige wechselt zu Gelb: ??#??
  • Den Regler drehen, der dem gewünschten Parameter zugeordnet ist. Die Anzeige „??#??“ erscheint nur bei diesem Parameter und signalisiert, dass er auf MIDI-learn wartet.
  • Einen Regler oder Fader bewegen oder ein CC-Pad antippen auf Ihrem externen MIDI-Controller. Die Zuweisung ist abgeschlossen; die Anzeige zeigt nun MIDI-Kanal und CC-Nummer in Weiß an.

Im MIDI-learn-Modus können Sie durch kräftiges Drücken der Regler auf die Parametersteuerungsoptionen zugreifen.

Sie können MIDI-learn jederzeit durch Drücken auf „Zurück“ abbrechen.

Parametersteuerungsoptionen

Drücken Sie im MIDI-learn-Modus einen beliebigen Regler kräftig, um die Controller-Optionen des zugehörigen Parameters aufzurufen. Dies sind die allgemeinen Optionen:

  • Chain Controller: Ist diese Option aktiviert, wird der Parameter am Anfang der Seitenliste zu den Chain-Controller-Seiten hinzugefügt. Diese Funktion dient als eine Art „Favoritenparameter“ für die chain.
  • X-Y-Touchpad: Wenn numerische Parameter für die X- und Y-Achse ausgewählt wurden, wird der X-Y-Touchpad-Modus aufgerufen.
  • Chain Learn: Chain MIDI Learn für den Parameter starten.
  • Global Learn: Global MIDI Learn für den Parameter starten.
  • Zynstep CC: Die CC-Nummer auswählen, mit der der Sequencer den Parameter automatisiert.
  • Unlearn: Die MIDI-Zuweisung des Parameters aufheben.
  • Unlearn all controls: Die MIDI-Zuweisungen aller Parameter im Prozessor aufheben.

Dies sind die spezifischen Optionen für numerische Controller:

  • Absolute/Relative Mode: Zum Konfigurieren inkrementeller Regler (Encoder).
  • CC Value Range: Konfigurieren, wie MIDI-CC-Werte dem zugehörigen Parameter zugeordnet werden.
  • X-axis: Aktivieren, um den Parameter im X-Y-Touchpad-Modus für die X-Achse zu verwenden.
  • Y-axis: Aktivieren, um den Parameter im X-Y-Touchpad-Modus für die Y-Achse zu verwenden.

Dies sind die spezifischen Optionen für Toggle-Controller:

  • Momentary => Latch: MIDI-CC-Impulse als Umschaltbefehle interpretieren (Latch-Modus).
  • Debounce: Entprellung aktivieren, um unerwünschte Schaltvorgänge zu vermeiden.

X-Y-Touchpad

Im X-Y-Touchpad-Modus können Sie die 2 zugewiesenen Parameter gleichzeitig mit dem Finger auf dem Touchscreen steuern – wie bei einem „Chaos-Pad“.
