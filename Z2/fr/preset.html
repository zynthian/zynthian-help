Vue des presets

La vue des presets permet de gérer les presets du processeur. Pour accéder à la vue des presets du processeur actif :

  • Depuis les vues chain-control ou chain-config, appuyez brièvement sur le bouton CTRL. Notez que la couleur du bouton CTRL passe du vert à l’orange.
  • Depuis toute autre vue, appuyez longuement sur le bouton CTRL. Notez que la couleur du bouton CTRL passe du bleu à l’orange.

Le processeur actif est celui qui est mis en surbrillance dans la chain active.

Dans la vue des presets, vous pouvez :

  • Tourner le bouton 4 ou utiliser les flèches HAUT/BAS pour parcourir la liste. Si le préchargement des presets est activé (voir la vue d’administration), le preset en surbrillance est préchargé lors du parcours de la liste.
  • Appuyer brièvement sur le bouton 4 ou sur le bouton SELECT pour sélectionner un preset pour le processeur.
  • Appuyer longuement sur le bouton 4 ou sur le bouton SELECT pour ouvrir les options du preset.
  • Appuyer brièvement sur le bouton CTRL pour accéder à la liste des banques. Appuyez de nouveau brièvement sur CTRL pour quitter la sélection des banques/presets.
  • Appuyer brièvement sur le bouton BACK pour quitter la sélection des banques/presets.

Les options des presets peuvent varier selon le processeur. Voici les options courantes :

  • [ ] Favori => Cochez cette option pour ajouter le preset à la liste des favoris.
  • Enregistrer comme nouveau preset => Enregistrer les réglages actuels des paramètres comme nouveau preset.
  • Supprimer le preset => Supprimer le preset. Disponible uniquement pour les presets utilisateur.
  • Rechercher de nouveaux presets => Par exemple, après avoir installé ou créé des presets depuis webconf.
