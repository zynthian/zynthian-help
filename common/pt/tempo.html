Vista de Tempo

A vista de tempo permite controlar a base de tempo do zynthian utilizada para sequenciação, arpeggiators, etc.

O controlo BPM define o tempo interno entre 10 e 420 BPM. Prima e rode para ajustar em passos de 0,1 BPM. Este controlo está disponível quando é utilizado o relógio interno.

Se for utilizado um relógio externo, o controlo BPM passa a funcionar como divisor de relógio. Por predefinição, espera uma entrada de 24 PPQN, utilizada pelo MIDI clock, mas pode ser ajustado para suportar outras frequências de relógio externo entre 1 e 48 PPQN. O relógio interno funciona a 1920 PPQN e utiliza um phase-locked loop para derivar este relógio de alta resolução a partir do relógio de entrada mais lento. Para utilizar um relógio externo, selecione «MIDI Clock Source» para uma entrada MIDI na vista Entrada MIDI.

O controlo Metronome Mode configura o metrónomo do zynthian. Tem os seguintes valores:

  • OFF: O metrónomo está desativado.
  • AUTO: O metrónomo toca enquanto houver uma sequência em reprodução e para no fim do compasso após a última sequência parar.
  • ON: O metrónomo toca continuamente.
  • INTRO: O metrónomo toca até uma sequência começar. Pode utilizar este modo como contagem de entrada quando não pretende ou não precisa que o metrónomo toque durante a atuação.
  • NO ACCENT: O metrónomo toca continuamente, mas sem acentuar o primeiro tempo de cada compasso. Funciona mais como um metrónomo tradicional, utilizado apenas para marcar o tempo e não a base de tempo.
  • SILENT: O metrónomo funciona, mas não produz som. Pode ser útil para fazer com que o transporte funcione quando não há sequências em reprodução. Alguns plugins podem beneficiar desta opção.
Existe um controlo para ajustar o volume do metrónomo.

É apresentado o tempo em tamanho grande e pode tocar nele para definir o tempo. Da mesma forma, pode tocar no botão de tempo para definir o tempo.

Nota: O metrónomo é encaminhado para a chain principal através do respetivo envio de mistura auxiliar, que permite controlar individualmente o nível, o balanço, etc. O leitor de áudio global partilha esta mistura auxiliar.
