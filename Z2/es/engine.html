Vista del selector de engines

El selector de engines permite explorar y seleccionar engines para el tipo elegido, que puede ser uno de los siguientes:

  • Sintetizador MIDI
  • Efecto de audio
  • Herramienta MIDI
  • Generador de audio
  • Especial

Esta vista aparece al añadir una nueva chain o al añadir/sustituir procesadores en una chain existente.

La vista está dividida en 3 columnas:

  • [Izquierda] Lista de categorías para el tipo elegido.
  • [Centro] Lista de engines para la categoría seleccionada. De forma predeterminada, solo se muestran los engines habilitados. Consulte modo avanzado más abajo.
  • [Derecha] Información sobre el engine resaltado, compuesta por:
    • Calidad: clasificada de 0 a 5 estrellas.
    • Complejidad: clasificada de 0 a 5 ruedas.
    • Descripción: un breve texto que describe las características del engine.

Puede realizar estas acciones:

  • Gire el knob 3 o pulse los botones LEFT/RIGHT para desplazarse por la lista de categorías.
  • Gire el knob 4 o pulse los botones UP/DOWN para desplazarse por la lista de engines.
  • Pulse el knob 4 para seleccionar el engine resaltado y cerrar el selector de engines.
  • Mantenga pulsado el knob 4 para acceder al modo avanzado, que muestra TODOS los engines y permite habilitarlos o deshabilitarlos.
  • Pulse el knob 3 para abrir la pantalla de información ampliada y leer descripciones largas.
  • Pulse BACK para volver a la vista anterior.

También puede usar la pantalla táctil en las listas de categorías y engines. Al tocar la columna de información, se abrirá la pantalla de información ampliada.

Modo avanzado

Para acceder al modo avanzado, mantenga pulsado el knob 4 o el botón SEL. En el modo avanzado se muestra la lista completa de engines, incluidos los deshabilitados, que normalmente están ocultos. Puede marcar o desmarcar los engines para habilitarlos o deshabilitarlos. Pulse BACK para volver al modo normal.
