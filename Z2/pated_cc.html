Pattern CC Editor

The pattern CC editor allows you to automate parameter changes by adding MIDI CC events to your sequencer patterns. For each pattern, you can automate up to 127 paramters using the 127 available CC numbers.

Before you can automate any parameter, you need to assign the parameters you want to automate to the CC numbers you want to use. There are 2 ways of doing this

  • Use MIDI learning to assign engine parameters to CC numbers. You would need a MIDI controller with knobs or faders.
  • From the engine parameter’s options menu, select ZynStep CC to assign a CC number by hand.

From the CC editor, proceed like this to create your CC patterns by hand:

  • Rotate knob 1 to select the CC number you want to edit. If the CC is already assigned, you will see the parameter name.
  • Rotate knob 4 to move the cursor along the pattern's time axis.
  • Short-push knob 4 to add/remove a point to the curve.
  • Rotate knob 3 to move the point (CC value) up & down.
  • Short-push knob 1 to back to the note editor.

You can use the finger to plot the curve and move points up & down. You can also live record (REC + PLAY) and move the assigned knob from your MIDI controller.

While playing, CC values are interpolated for every clock tick (1920 ticks per quarter note). CC interpolation is enabled by default except for pedals (i.e. CC64).

From the pattern options menu, you can toggle CC interpolation for each CC number, clean the CC pattern while keeping notes and much more.

Of course, all these can be done while the pattern is playing, so you will hear the result inmediatelly, while adjusting your CC values in real time.
