Vue sélecteur

Le sélecteur est une vue générique qui affiche une liste d’options sélectionnables. Des en-têtes non sélectionnables peuvent séparer les différentes sections de la liste.

La sélection d’une entrée peut ouvrir une autre vue, activer ou désactiver une option, ou ouvrir l’éditeur de paramètres. Tournez le bouton 4 pour parcourir la liste, puis appuyez pour sélectionner l’élément. D’autres actions peuvent être disponibles avec un appui long. Utilisez BACK pour quitter.

Dans le panneau latéral droit, des conseils ou des informations décrivant l’élément sélectionné s’affichent sous l’icône. Si le texte est trop long, faites-le défiler avec le bouton 3. Appuyez sur le bouton 3 pour afficher des détails supplémentaires, le cas échéant.
