Engine Selector View

The engine selector allows browsing and selecting engines for the chosen type, that can be one of these:

  • MIDI Synth
  • Audio Effect
  • MIDI Tool
  • Audio Generator
  • Special

You reach this view when adding a new chain or adding/replacing processors in an existing chain.

The view is splitted in 3 columns:

  • [Left] Category list for the chosen type.
  • [Center] Engine list for the selected category. Only enabled engines are shown by default. See advanced mode below.
  • [Right] Information for the highlighted engine, composed of:
    • Quality: ranked with 0 to 5 starts.
    • Complexity: ranked with 0 to 5 wheels.
    • Description: a short text describing the engine's features.

You can perform these actions:

  • Rotate knob 3 (LEARN/SHOT) to move across the category list.
  • Rotate knob 4 (SELECT) to move across the engine list.
  • Push knob 4 to select the highlighted engine and close the engine selector.
  • Bold-push knob 4 to enter advanced mode, that shows ALL engines, allowing to enable/disable.
  • Push knob 3 to open the extended info screen to read long descriptions.
  • Push knob 2 (BACK) to return to the previous view.

You can also use touch in the category and engine list. Touching in the info column will open the extended info screen.

Advanced Mode

You enter advanced mode by bold-pushing knob 4. In advanced mode, the full list of engines is shown, including disabled engines that are normally hidden. You can check/uncheck the engines to enable/disable. Push BACK to return to normal mode.
