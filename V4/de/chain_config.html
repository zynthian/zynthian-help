Chain-Konfigurationsansicht

In der Chain-Konfigurationsansicht, auch als Auswahlmodus bekannt, können Sie alle Aspekte einer chain konfigurieren.

Das Bedienfeld auf der linken Seite enthält die Liste der Blöcke, aus denen Ihre chain besteht, einschließlich der Processor. Das rechte Bedienfeld zeigt eine reduzierte Version der chain-Steuerungsansicht. Verwenden Sie Knob 3, um die chain-Blöcke links zu durchblättern, und Knob 4, um die Liste rechts zu durchblättern.

Zum Beenden drücken Sie einfach kurz BACK. Dadurch kehren Sie zur chain-Steuerungsansicht zurück.

Die chain-Blöcke im linken Bedienfeld funktionieren ähnlich wie in der chain-Manager-Ansicht und hängen vom chain-Typ und den Processor ab. Folgende Blöcke sind möglich:

  • Chain-Optionen
  • MIDI-Eingang
  • Audio-Eingang
  • MIDI-Processor
  • Synth-Processor
  • Audio-Processor
  • MIDI-Ausgang
  • Audio-Ausgang

Processor-Blöcke

Wenn ein Processor ausgewählt ist, wird die rechte Liste so positioniert, dass die Parameterseiten dieses Processor angezeigt werden. Sie können die Optionen des Processor mit einem kurzen Druck auf Knob 3 oder durch ein zweites Tippen auf den Block auf einem Touchscreen aufrufen.

Blöcke ohne Processor

Wenn ein Block ohne Processor ausgewählt ist, beispielsweise Chain-Optionen, MIDI-Eingang usw., wird im rechten Bedienfeld ein Konfigurationsbereich angezeigt. Mit Knob 4 drehen können Sie durch die Optionen navigieren und mit einem kurzen Druck auf Knob 4 Optionen auswählen bzw. aktivieren. Wenn eine Option Unteroptionen enthält, können Sie das Menü mit den Unteroptionen durch einen kräftigen Druck auf Knob 4 aufrufen.
