Vista de presets

La vista de presets permite gestionar los presets del procesador. Para acceder a la vista de presets del procesador activo:

  • Desde las vistas chain-control o chain-config, pulsa brevemente el botón CTRL. Ten en cuenta que el color del botón CTRL cambia de verde a naranja.
  • Desde cualquier otra vista, mantén pulsado el botón CTRL. Ten en cuenta que el color del botón CTRL cambia de azul a naranja.

El procesador activo es el procesador resaltado en la chain activa.

Una vez en la vista de presets, puedes:

  • Girar el knob-4 o usar los botones de flecha ARRIBA/ABAJO para recorrer la lista. Si la opción precarga de presets está activada (consulta la vista de administración), el preset resaltado se precargará al desplazarse por la lista.
  • Pulsar brevemente el knob-4 o el botón SELECT para seleccionar un preset para el procesador.
  • Mantener pulsado el knob-4 o el botón SELECT para abrir las opciones del preset.
  • Pulsar brevemente el botón CTRL para acceder a la lista de bancos. Vuelve a pulsar brevemente CTRL para salir de la selección de bancos/presets.
  • Pulsar brevemente el botón BACK para salir de la selección de bancos/presets.

Las opciones de los presets pueden variar según el procesador. Estas son las opciones habituales:

  • [ ] Favorito => Marca esta opción para añadir el preset a la lista de favoritos.
  • Guardar como nuevo preset => Guarda los ajustes actuales de los parámetros como un preset nuevo.
  • Eliminar preset => Elimina el preset. Solo está disponible para los presets de usuario.
  • Buscar nuevos presets => Por ejemplo, cuando instalas o creas presets desde webconf.
