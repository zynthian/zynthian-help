Vista de controlo da chain

A vista de controlo da chain permite aceder aos parâmetros dos processadores na chain ativa. Pode:

  • Modificar o valor dos parâmetros do processador rodando os knobs.
  • Entrar no modo MIDI learn premindo brevemente o knob 3.

Os parâmetros dos processadores estão agrupados em páginas, com até 4 parâmetros por página. Selecione as páginas utilizando os botões S3 / S4. A lista contém as páginas de controlo de todos os processadores da chain.

Para percorrer as páginas mais rapidamente, entre no modo de seleção com uma pressão breve no knob 4.

Tenha em atenção que o modo de seleção também é conhecido como vista de configuração da chain.

MIDI Learn

Pode associar qualquer parâmetro a knobs, faders e pads CC dos seus controladores MIDI externos. Existem 2 modos MIDI learn diferentes:

  • Chain Learn: A associação aplica-se apenas à chain selecionada. Pode associar o mesmo knob a um ou vários parâmetros na mesma chain ou em chains diferentes. Apenas a chain selecionada reagirá à mensagem MIDI CC.
  • Global Learn: A associação é global. Pode associar o mesmo knob a um ou vários parâmetros na mesma chain ou em chains diferentes. Todos reagirão, independentemente da chain selecionada.
O procedimento de MIDI learn é o seguinte:
  • Prima brevemente o knob 3. É apresentado um indicador ##?## em todos os parâmetros, indicando o modo Chain Learn. Se necessário, prima novamente para entrar no modo MIDI Learn global. O indicador mudará para amarelo: ??#??
  • Rode o knob associado ao parâmetro que pretende configurar. O indicador "??#??" será apresentado apenas nesse parâmetro, indicando que está à espera de uma associação MIDI learn.
  • Mova um knob/fader ou toque num pad CC no seu controlador MIDI externo. A associação está concluída e o indicador apresenta agora o canal MIDI e o número CC a branco.

Enquanto estiver no modo MIDI learn, pode aceder às opções de controlo dos parâmetros premindo demoradamente os knobs.

Pode cancelar o MIDI learn em qualquer momento premindo «voltar».

Opções de controlo dos parâmetros

Enquanto estiver no modo MIDI learn, prima demoradamente qualquer knob para aceder às opções do controlador para o parâmetro associado. Estas são as opções comuns:

  • Chain Controller: Quando selecionada, esta opção adiciona o parâmetro às páginas do controlador da chain, no início da lista de páginas. Esta funcionalidade funciona como uma espécie de «parâmetros favoritos» da chain.
  • X-Y Touchpad: Quando tiverem sido selecionados parâmetros numéricos para os eixos X e Y, entre no modo X-Y Touchpad.
  • Chain Learn: Inicia o MIDI learn da chain para o parâmetro.
  • Global Learn: Inicia o MIDI learn global para o parâmetro.
  • Zynstep CC: Escolha o número CC utilizado pelo sequenciador para automatizar o parâmetro.
  • Unlearn: Remove a associação do parâmetro.
  • Unlearn all controls: Remove as associações de todos os parâmetros do processador.

Estas são as opções específicas para controladores numéricos:

  • Absolute/Relative Mode: Permite configurar knobs incrementais (encoders).
  • CC Value Range: Configura a forma como os valores MIDI CC são mapeados para o parâmetro associado.
  • X-axis: Selecione para utilizar o parâmetro no eixo X no modo X-Y Touchpad.
  • Y-axis: Selecione para utilizar o parâmetro no eixo Y no modo X-Y Touchpad.

Estas são as opções específicas para controladores de alternância:

  • Momentary => Latch: Interpreta os impulsos MIDI CC como alternâncias (modo latch).
  • Debounce: Ativa o debounce para evitar comutações espúrias.

X-Y Touchpad

No modo X-Y Touchpad, pode controlar os 2 parâmetros atribuídos em simultâneo, deslizando o dedo pelo ecrã tátil, «à la chaos-pad».
