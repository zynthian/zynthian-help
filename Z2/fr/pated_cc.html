Éditeur de CC du pattern

L’éditeur de CC du pattern vous permet d’automatiser les changements de paramètres en ajoutant des événements MIDI CC à vos patterns de séquenceur. Le menu contextuel (OPT) permet de modifier les paramètres du pattern et les options d’édition.

Les boutons PLAY/STOP permettent de lire et d’arrêter le pattern. Le bouton REC active l’enregistrement MIDI CC en temps réel pendant la lecture.

Le mode ALT permet d’accéder à des fonctions spéciales telles que l’annulation/le rétablissement et la copie/le collage de patterns.

L’enregistrement en temps réel, l’annulation/le rétablissement et la copie/le collage de patterns sont également pris en charge par l’éditeur de CC et fonctionnent de la même manière que dans l’éditeur de notes.

Fonctionnement de base

Pour chaque pattern, vous pouvez automatiser jusqu’à 127 paramètres à l’aide des 127 numéros de CC disponibles.

Avant de pouvoir automatiser un paramètre, vous devez associer les paramètres à automatiser aux numéros de CC que vous souhaitez utiliser. Il existe deux façons de procéder :

  • Utilisez le MIDI-learning pour associer les paramètres de l’engine à des numéros de CC. Vous aurez besoin d’un contrôleur MIDI équipé de knobs ou de faders.
  • Dans le menu d’options du paramètre de l’engine, sélectionnez ZynStep CC pour attribuer manuellement un numéro de CC.

Une fois le paramètre à automatiser associé, procédez comme suit dans l’éditeur de CC pour créer manuellement votre pattern de CC :

  • Tournez le knob 1 pour sélectionner le numéro de CC à modifier. Si le CC est déjà associé, le nom du paramètre s’affiche.
  • Tournez le knob 4 pour déplacer le curseur le long de l’axe temporel du pattern.
  • Appuyez brièvement sur le knob 4 pour ajouter ou supprimer un point sur la courbe.
  • Tournez le knob 3 pour déplacer le point (valeur CC) vers le haut ou vers le bas.
  • Appuyez brièvement sur le knob 1 pour revenir à l’éditeur de notes.

Vous pouvez tracer la courbe avec le doigt et déplacer les points vers le haut ou vers le bas. Vous pouvez également enregistrer en temps réel (REC + PLAY) et actionner le knob associé depuis votre contrôleur MIDI.

Pendant la lecture, les valeurs CC sont interpolées à chaque impulsion d’horloge (1 920 impulsions par noire). L’interpolation des CC est activée par défaut, sauf pour les pédales (c’est-à-dire CC64).

Dans le menu des options du pattern, vous pouvez activer ou désactiver séparément l’interpolation des CC pour chaque numéro de CC, effacer le pattern de CC tout en conservant les notes, et bien plus encore.

Bien entendu, toutes les modifications et tous les réglages de paramètres peuvent être effectués pendant la lecture du pattern. Vous entendez ainsi immédiatement le résultat lorsque vous modifiez les valeurs CC en temps réel.

Enregistrement de patterns

Appuyez sur le bouton REC pour activer l’enregistrement MIDI. Lorsque l’enregistrement est armé, le bouton REC s’allume en rouge.

Enregistrement pas à pas

Cette fonction n’est pas prise en charge pour les événements CC.

Enregistrement en temps réel

Si le pattern est en cours de lecture, les événements de notes et de CC sont enregistrés en temps réel. Ils sont enregistrés au moment précis où ils sont capturés, sans quantification. Si nécessaire, la quantification peut être appliquée à la lecture (voir le menu des options du pattern). Lors de l’enregistrement en temps réel, l’historique est sauvegardé à chaque boucle du pattern, uniquement si de nouvelles notes ont été enregistrées.

Annuler/Rétablir

En mode ALT, vous pouvez utiliser les touches fléchées pour annuler ou rétablir une action :

  • LEFT : annuler la dernière opération de modification.
  • RIGHT : rétablir la dernière opération annulée.
  • DOWN : tout annuler.
  • UP : tout rétablir.

Il existe une autre méthode pour annuler ou rétablir des actions, qui peut être utilisée par commodité ou lorsque le mode ALT n’est pas facilement accessible :

  • lorsque l’enregistrement est armé (le bouton REC est allumé en rouge)…
  • appuyez longuement sur le bouton BACK pour accéder au mode de navigation dans l’historique.
  • tournez le knob 4 pour parcourir l’historique.
  • appuyez sur BACK pour quitter ce mode.

Notez que, même si le nombre d’étapes de l’historique est illimité, l’historique n’est pas enregistré dans l’état et sera perdu lors du chargement du snapshot. Les snapshots enregistrent uniquement le dernier état.

Options du pattern

Appuyez brièvement sur ALT pour ouvrir le menu des options du pattern, qui permet de modifier les propriétés du pattern ainsi que diverses options d’édition. Voici les paramètres du pattern :

  • Rename : modifier le nom de la séquence affiché sur les pads du launcher.
  • Play mode : DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, … PLAY 24 TIMES
  • Program Change : numéro de program-change déclenché avec le pattern. Il peut servir à changer les ZS3, etc.
  • Length : longueur du pattern en mesures et en temps.
  • Steps/Beat : nombre de pas par temps. Le pas est la plus petite unité temporelle de la grille du pattern, mais la position et la durée des événements peuvent être réglées par fractions de pas.
  • Quantization : la quantification peut être DISABLED ou réglée sur 1, 1/2, 1/3, 1/4 ou 1/6 de pas.
  • Swing Amount : quantité de swing en %.
  • Swing Divisor : nombre de subdivisions utilisées pour le swing. Utilisez 1 avec 30 % pour obtenir un swing ternaire parfait.
  • Time Humanization : randomiser le timing des notes selon une distribution gaussienne afin de simuler les imprécisions humaines.
  • Interpolate CC## values : activer ou désactiver l’interpolation des valeurs CC pour le numéro de CC sélectionné.

Options d’édition

  • Copy this to clipboard : copier le pattern dans le presse-papiers.
  • Paste from clipboard : coller le contenu du presse-papiers dans le pattern actuel.
  • Load pattern : charger un pattern depuis un fichier.
  • Save pattern : enregistrer le pattern dans un fichier.
  • Import from SMF : charger un pattern depuis un fichier Standard MIDI (.mid).
  • Export to SMF : enregistrer le pattern dans un fichier Standard MIDI (.mid).
  • Clear pattern ALL : supprimer toutes les notes et tous les événements CC du pattern.
  • Clear pattern CC## : supprimer du pattern tous les événements CC correspondant au numéro de CC sélectionné.
