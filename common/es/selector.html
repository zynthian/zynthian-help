Vista Selector

El selector es una vista genérica que muestra una lista de opciones seleccionables. Puede haber encabezados no seleccionables que dividan la lista en secciones.

Al seleccionar una entrada, puede abrirse otra vista, activarse o desactivarse una opción o abrirse el editor de parámetros. Gire el mando 4 para recorrer la lista y púlselo para seleccionar el elemento. Puede haber otras acciones disponibles al pulsar con fuerza. Use BACK para salir.

En el panel lateral derecho, debajo del icono, se mostrarán consejos o información sobre el elemento seleccionado. Si el texto es demasiado largo, puede desplazarse con el mando 3. Al pulsar el mando 3, pueden mostrarse más detalles, si están disponibles.
