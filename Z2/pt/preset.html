Vista de presets

A vista de presets permite gerir os presets do processador. Para aceder à vista de presets do processador ativo:

  • Nas vistas chain-control ou chain-config, prima brevemente o botão CTRL. Note que a cor do botão CTRL muda de verde para laranja.
  • Em qualquer outra vista, prima prolongadamente o botão CTRL. Note que a cor do botão CTRL muda de azul para laranja.

O processador ativo é o processador realçado na chain ativa.

Na vista de presets, pode:

  • Rodar o knob-4 ou usar os botões de seta PARA CIMA/PARA BAIXO para percorrer a lista. Se a opção preset preload estiver ativada (consulte a vista de administração), o preset realçado será pré-carregado ao percorrer a lista.
  • Premir brevemente o knob-4 ou o botão SELECT para selecionar um preset para o processador.
  • Premir prolongadamente o knob-4 ou o botão SELECT para abrir as opções do preset.
  • Premir brevemente o botão CTRL para aceder à lista de banks. Prima brevemente CTRL novamente para sair da seleção de bank/preset.
  • Premir brevemente o botão BACK para sair da seleção de bank/preset.

As opções do preset podem variar consoante o processador. Estas são as opções de preset mais comuns:

  • [ ] Favorite => Assinale para adicionar o preset à lista de favoritos.
  • Save as new preset => Guarda os ajustes atuais dos parâmetros como um novo preset.
  • Delete preset => Elimina o preset. Disponível apenas para presets do utilizador.
  • Scan for new presets => Por exemplo, quando instala ou cria presets através do webconf.
