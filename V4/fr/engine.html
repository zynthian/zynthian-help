Vue de sélection des engines

Le sélecteur d’engine permet de parcourir et de sélectionner des engines pour le type choisi, qui peut être l’un des suivants :

  • MIDI Synth
  • Audio Effect
  • MIDI Tool
  • Audio Generator
  • Special

Cette vue s’affiche lorsque vous ajoutez une nouvelle chaîne ou que vous ajoutez/remplacez des processors dans une chaîne existante.

La vue est divisée en 3 colonnes :

  • [Gauche] Liste des catégories pour le type choisi.
  • [Centre] Liste des engines pour la catégorie sélectionnée. Seuls les engines activés sont affichés par défaut. Voir le mode avancé ci-dessous.
  • [Droite] Informations sur l’engine sélectionné, composées de :
    • Qualité : notée de 0 à 5 étoiles.
    • Complexité : notée de 0 à 5 roues.
    • Description : un court texte décrivant les fonctionnalités de l’engine.

Vous pouvez effectuer les actions suivantes :

  • Tournez le bouton 3 (LEARN/SHOT) pour parcourir la liste des catégories.
  • Tournez le bouton 4 (SELECT) pour parcourir la liste des engines.
  • Appuyez sur le bouton 4 pour sélectionner l’engine en surbrillance et fermer le sélecteur d’engine.
  • Maintenez le bouton 4 enfoncé pour passer en mode avancé, qui affiche TOUS les engines et permet de les activer/désactiver.
  • Appuyez sur le bouton 3 pour ouvrir l’écran d’informations détaillées et lire les descriptions complètes.
  • Appuyez sur le bouton 2 (BACK) pour revenir à la vue précédente.

Vous pouvez également toucher les listes des catégories et des engines. Si vous touchez la colonne d’informations, l’écran d’informations détaillées s’ouvre.

Mode avancé

Vous passez en mode avancé en maintenant le bouton 4 enfoncé. En mode avancé, la liste complète des engines s’affiche, y compris les engines désactivés, normalement masqués. Vous pouvez cocher/décocher les engines pour les activer/désactiver. Appuyez sur BACK pour revenir au mode normal.
