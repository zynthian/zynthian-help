Vue de configuration de chain

La vue de configuration de chain, également appelée mode de sélection, permet de configurer tous les aspects d'une chain.

Le panneau latéral gauche contient la liste des blocs qui configurent votre chain, y compris les processors. Le panneau de droite affiche une version réduite de la vue contrôle de chain. Utilisez le bouton 3 pour parcourir les blocs de chain à gauche et le bouton 4 pour parcourir la liste de droite.

Pour quitter, il suffit d'effectuer une pression brève sur BACK, ce qui vous ramène à la vue contrôle de chain.

Les blocs de chain du panneau gauche fonctionnent de la même manière que dans la vue du gestionnaire de chain et dépendent du type de chain et des processors. Il peut s'agir de :

  • Options de chain
  • Entrée MIDI
  • Entrée audio
  • Processors MIDI
  • Synth Processor
  • Processors audio
  • Sortie MIDI
  • Sortie audio

Blocs de processor

Lorsqu'un processor est sélectionné, la liste de droite est repositionnée pour afficher les pages de paramètres de ce processor. Vous pouvez accéder aux options du processor en effectuant une pression brève sur le bouton 3 ou en touchant une deuxième fois le bloc sur un écran tactile.

Blocs sans processor

Lorsqu'un bloc sans processor est sélectionné, comme Options de chain, Entrée MIDI, etc., un panneau de configuration s'affiche dans le panneau de droite. Vous pouvez parcourir les options en tournant le bouton 4 et sélectionner/cocher les options en effectuant une pression brève sur le bouton 4. Si l'option comporte des sous-options, vous pouvez accéder au menu correspondant en effectuant une pression longue sur le bouton 4.
