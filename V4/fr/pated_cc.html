Éditeur CC de pattern

L'éditeur CC de pattern permet d'automatiser les changements de paramètres en ajoutant des événements MIDI CC à vos patterns du séquenceur. Le menu contextuel (appui court sur le potentiomètre 1) permet de modifier les paramètres du pattern et les options d'édition.

L'enregistrement en temps réel, l'annulation/le rétablissement et le copier/coller de patterns sont également pris en charge par l'éditeur CC, et fonctionnent de la même manière que dans l'éditeur de notes.

Fonctionnement de base

Pour chaque pattern, vous pouvez automatiser jusqu'à 127 paramètres à l'aide des 127 numéros CC disponibles.

Avant d'automatiser un paramètre, vous devez l'associer au numéro CC que vous souhaitez utiliser. Il existe deux façons de procéder :

  • Utilisez le MIDI learning pour associer des paramètres de moteur à des numéros CC. Vous aurez besoin d'un contrôleur MIDI doté de potentiomètres ou de faders.
  • Dans le menu des options du paramètre de moteur, sélectionnez ZynStep CC pour attribuer manuellement un numéro CC.

Une fois le paramètre à automatiser associé, procédez comme suit dans l'éditeur CC pour créer manuellement votre pattern CC :

  • Tournez le potentiomètre 1 pour sélectionner le numéro CC à modifier. Si le CC est déjà associé, le nom du paramètre s'affiche.
  • Tournez le potentiomètre 4 pour déplacer le curseur sur l'axe temporel du pattern.
  • Appuyez brièvement sur le potentiomètre 4 pour ajouter ou supprimer un point sur la courbe.
  • Tournez le potentiomètre 3 pour déplacer le point (valeur CC) vers le haut ou vers le bas.
  • Appuyez brièvement sur S4 pour revenir à l'éditeur de notes.

Vous pouvez dessiner la courbe avec le doigt et déplacer les points vers le haut ou vers le bas. Vous pouvez également enregistrer en temps réel (REC + PLAY) et tourner le potentiomètre associé sur votre contrôleur MIDI.

Pendant la lecture, les valeurs CC sont interpolées à chaque tick d'horloge (1920 ticks par noire). L'interpolation CC est activée par défaut, sauf pour les pédales (par exemple, CC64).

Dans le menu des options du pattern, vous pouvez activer ou désactiver séparément l'interpolation CC pour chaque numéro CC, effacer le pattern CC tout en conservant les notes, et bien plus encore.

Bien entendu, vous pouvez modifier et ajuster les paramètres pendant la lecture du pattern ; vous entendrez donc immédiatement le résultat lorsque vous modifiez les valeurs CC en temps réel.

Enregistrement de patterns

Appuyez longuement sur le potentiomètre 3 pour activer l'enregistrement MIDI. Lorsque l'enregistrement est armé, un cercle jaune s'allume dans la barre d'état.

Capture pas à pas

Cette fonction n'est pas prise en charge pour les événements CC.

Capture en temps réel

Si le pattern est en lecture (appui court sur le potentiomètre 3), les événements de notes et CC sont capturés en temps réel. Ils sont enregistrés au moment précis de leur capture, sans quantification. Si nécessaire, une quantification peut être appliquée à la lecture (voir le menu des options du pattern). Pendant la capture en temps réel, l'historique est enregistré à chaque boucle du pattern, uniquement si de nouvelles notes ont été capturées.

Annuler/Rétablir

Vous pouvez annuler ou rétablir la plupart des opérations d'édition en suivant la procédure ci-dessous :

  • Appuyez longuement sur le potentiomètre 2 (BACK) pour passer en mode de navigation dans l'historique.
  • Tournez le potentiomètre 4 pour parcourir l'historique.
  • Appuyez brièvement sur le potentiomètre 2 (BACK) pour quitter ce mode.

Notez que, même si le nombre d'étapes de l'historique est illimité, celui-ci n'est pas enregistré dans l'état et sera perdu lors du prochain chargement du snapshot. Les snapshots enregistrent uniquement le dernier état.

Options du pattern

Appuyez brièvement sur le potentiomètre 1 pour ouvrir le menu des options du pattern, qui permet de modifier les propriétés du pattern ainsi que diverses options d'édition. Voici les paramètres du pattern :

  • Rename : Modifier le nom de la séquence affiché sur les pads du launcher.
  • Play mode : DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change : Numéro de program-change déclenché avec le pattern. Il peut servir à modifier les ZS3, etc.
  • Length : Longueur du pattern en mesures et en temps.
  • Steps/Beat : Nombre de pas par temps. Le pas est la plus petite unité de temps de la grille du pattern, mais la position et la durée des événements peuvent être ajustées par fractions de pas.
  • Quantization : La quantification peut être désactivée ou réglée sur 1, 1/2, 1/3, 1/4 ou 1/6 de pas.
  • Swing Amount : Intensité du swing en %.
  • Swing Divisor : Nombre de subdivisions utilisées pour le swing. Utilisez 1 avec 30 % pour obtenir un swing ternaire parfait.
  • Time Humanization : Randomiser le timing des notes selon une distribution gaussienne afin de simuler les imprécisions humaines.
  • Interpolate CC## values : Activer ou désactiver l'interpolation des valeurs CC pour le numéro CC sélectionné.

Options d'édition

  • Copy this to clipboard : Copier le pattern dans le presse-papiers.
  • Paste from clipboard : Coller le contenu du presse-papiers dans le pattern actuel.
  • Load pattern : Charger un pattern depuis un fichier.
  • Save pattern : Enregistrer le pattern dans un fichier.
  • Import from SMF : Charger un pattern depuis un fichier MIDI standard (.mid)
  • Export to SMF : Enregistrer le pattern dans un fichier MIDI standard (.mid)
  • Clear pattern ALL : Supprimer toutes les notes et tous les événements CC du pattern.
  • Clear pattern CC## : Supprimer du pattern tous les événements CC correspondant au numéro CC sélectionné.
