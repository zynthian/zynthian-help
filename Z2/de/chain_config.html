Chain-Konfigurationsansicht

In der Chain-Konfigurationsansicht, auch Auswahlmodus genannt, können Sie jeden Aspekt einer chain konfigurieren.

Das linke Bedienfeld enthält die Liste der Blöcke, mit denen Ihre chain konfiguriert wird, einschließlich der Prozessoren. Das rechte Bedienfeld zeigt eine reduzierte Version der Ansicht Chain-Steuerung. Verwenden Sie Regler 3, um die chain-Blöcke auf der linken Seite zu durchsuchen, und Regler 4, um die Liste auf der rechten Seite zu durchsuchen.

Um die Ansicht zu verlassen, drücken Sie BACK kurz. Dadurch gelangen Sie zurück zur Ansicht Chain-Steuerung.

Die chain-Blöcke im linken Bedienfeld funktionieren ähnlich wie in der Chain-Verwaltungsansicht und hängen vom chain-Typ und den Prozessoren ab. Folgende Blöcke sind möglich:

  • Chain-Optionen
  • MIDI-Eingang
  • Audio-Eingang
  • MIDI-Prozessoren
  • Synth-Prozessor
  • Audio-Prozessoren
  • MIDI-Ausgang
  • Audio-Ausgang

Prozessorblöcke

Wenn ein Prozessor ausgewählt ist, wird die rechte Liste so verschoben, dass die Parameterseiten dieses Prozessors angezeigt werden. Sie können die Prozessoroptionen mit einem kurzen Druck auf Regler 3, einem kurzen Druck auf OPT oder durch ein zweites kurzes Antippen des Blocks auf einem Touchscreen aufrufen.

Blöcke ohne Prozessoren

Wenn ein Block ohne Prozessor ausgewählt ist, etwa Chain-Optionen, MIDI-Eingang usw., wird im rechten Bedienfeld ein Konfigurationsfeld angezeigt. Mit Drehen von Regler 4 können Sie durch die Optionen navigieren und sie mit einem kurzen Druck auf Regler 4 auswählen bzw. aktivieren. Alternativ können Sie die Tasten UP/DOWN und SELECT verwenden. Wenn die Option Unteroptionen enthält, können Sie das Unteroptionenmenü mit einem kräftigen Druck auf Regler 4, einem kräftigen Druck auf SELECT oder einem kurzen Druck auf OPT aufrufen.
