Pattern CC Editor

The pattern CC editor allows you to automate parameter changes by adding MIDI CC events to your sequencer patterns. The contextual menu (shot-push knob 1) allows modifying the pattern parameters and edit options.

Live recording, undo/redo and copy/paste patterns are also supported by the CC editor and they work very much as they do in the note editor.

Basic Operation

For each pattern, you can automate up to 127 paramters using the 127 available CC numbers.

Before you can automate any parameter, you need to assign the parameters you want to automate to the CC numbers you want to use. There are 2 ways of doing this

  • Use MIDI learning to assign engine parameters to CC numbers. You would need a MIDI controller with knobs or faders.
  • From the engine parameter’s options menu, select ZynStep CC to assign a CC number by hand.

Once you have assigned the parameter you want to automate, from the CC editor, proceed like this to create your CC pattern by hand:

  • Rotate knob 1 to select the CC number you want to edit. If the CC is already assigned, you will see the parameter name.
  • Rotate knob 4 to move the cursor along the pattern's time axis.
  • Short-push knob 4 to add/remove a point to the curve.
  • Rotate knob 3 to move the point (CC value) up & down.
  • Short-push S4 to back to the note editor.

You can use the finger to plot the curve and move points up & down. You can also live record (REC + PLAY) and move the assigned knob from your MIDI controller.

While playing, CC values are interpolated for every clock tick (1920 ticks per quarter note). CC interpolation is enabled by default except for pedals (i.e. CC64).

From the pattern options menu, you can toggle CC interpolation for each CC number separatelly, clean the CC pattern while keeping notes and much more.

Of course, all editing and parameter adjusting can be done while the pattern is playing, so you will hear the result inmediatelly, while modifying CC values in real time.

Recording Patterns

Bold-push knob 3 to enable MIDI recording. While record is armed, the yellow circle symbol will light in the status bar.

Step by Step Capture

It's not supported for CC events.

Live Capture

If the pattern is playing (short-push knob 3), note and CC events will be captured in real time. They are recorded at the exact time they are captured, without quantization. If desired, quantization can be applied to replaying (see pattern options menu). While live capturing, history is saved on each pattern loop, only if new notes were captured.

Undo/Redo

You can undo/redo most edit operations using the next procedure:

  • bold-push knob 2 (BACK) to enter history navigation mode.
  • rotate knob 4 to move along the history.
  • short push knob 2 (BACK) to end.

Note that although the number of history steps is unlimited, history is not saved in the state and will be lost when loading the snapshot again. Snapshots will save the last state only.

Pattern Options

Short-push knob 1 to open the pattern options menu that let you modify the pattern properties as well as a bunch of edit options. These are the pattern parameters:

  • Rename: Change the sequence's name displayed in the launcher's pads.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: The program change number that is triggered with the pattern. It can be used for changing ZS3s, etc.
  • Length: The pattern length in bars and beats.
  • Steps/Beat: The number of steps per beat. The step is the smaller unit of time in the pattern grid, but event's position and duration can be adjusted by fraction of step.
  • Quantization: Quantization can be DISABLED or set to 1, 1/2, 1/3, 1/4, 1/6 step.
  • Swing Amount: The amount of swing in %.
  • Swing Divisor: The number of divisions used for swing. Use 1 with 30% to get a perfect ternary swing.
  • Time Humanization: Randomize note's time following a gauss distribution to simulate human imprecission.
  • Interpolate CC## values: Toggle CC value interpolation for the selected CC number.

Edit options

  • Copy this to clipboard: Copy the pattern to the clipboard.
  • Paste from clipboard: Paste the content of clipboard to the current pattern.
  • Load pattern: Load a pattern from file.
  • Save pattern: Save the pattern to a file.
  • Import from SMF: Load a pattern from a Standard MIDI File (.mid)
  • Export to SMF: Save the pattern to a Standard MIDI File (.mid)
  • Clear pattern ALL: Delete all notes & CC events from the pattern.
  • Clear pattern CC##: Delete all CC events from the pattern for the selected CC number.
