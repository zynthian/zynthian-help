Gestionnaire de chain

Cette vue présente les chain et leurs éléments sous forme de grille déroulante. (Avec un écran tactile, vous pouvez déplacer la vue en faisant glisser l’arrière-plan.) Les chain apparaissent de gauche à droite sous forme de colonnes de blocs interconnectés représentant les entrées, les processeurs, les sorties, etc., le flux du signal allant de haut en bas. La chain principale se trouve toujours tout à droite.

Chain

Chaque chain se compose d’un ou plusieurs processeurs. Ceux-ci sont représentés par des blocs disposés dans une colonne verticale. Le signal audio et/ou MIDI circule de haut en bas. Les processeurs peuvent être en parallèle ; dans ce cas, des colonnes supplémentaires affichent les processeurs parallèles sur la même ligne.

La chain peut comporter les éléments suivants, sur lesquels vous pouvez appuyer ou que vous pouvez sélectionner pour afficher leur menu contextuel :

  • Options de la chain : elles se trouvent toujours en haut de chaque chain et indiquent son nom.
  • Entrée MIDI : disponible pour les chain Synth et MIDI
  • Entrée audio : disponible pour les chain Audio Input
  • Processeurs MIDI : le cas échéant
  • Processeur Synth : le cas échéant
  • Processeurs audio : le cas échéant
  • Sortie MIDI : disponible pour les chain MIDI
  • Sortie audio : disponible pour les chain Synth et Audio
Remarque : les chain Audio comportent un processeur de mixage audio, qui fonctionne comme les autres processeurs audio, mais ne peut pas être placé en parallèle. De même, les processeurs Synth ne peuvent pas être placés en parallèle.

Parcourez la grille à l’aide des potentiomètres 3 et 4 ou des touches fléchées, puis ouvrez le menu contextuel d’un élément en appuyant brièvement sur le potentiomètre 4 ou sur SELECT.

Pour déplacer un processeur, appuyez longuement sur le potentiomètre 4 pour activer le mode de déplacement des processeurs. Un contour jaune indique qu’un processeur va être déplacé. Utilisez le potentiomètre 3 pour déplacer le processeur vers le haut ou le bas de la chain. Lorsqu’il passe à côté d’autres processeurs, il apparaît d’abord en parallèle, puis en série. Utilisez le potentiomètre 4 pour déplacer le processeur vers une autre chain. Appuyez sur BACK pour quitter le mode de déplacement des processeurs. Sur un écran tactile, appuyez longuement sur le processeur pour activer le mode de déplacement, puis faites glisser le processeur. Appuyez brièvement pour quitter le mode de déplacement.

Pour ajouter une nouvelle chain, appuyez brièvement sur le potentiomètre 3. Cette action est également disponible dans les vues Mixer et Launcher. Vous pouvez aussi ouvrir le menu principal en appuyant brièvement sur OPT (V5) ou longuement sur BACK (V4).

Ordre d’affichage

L’ordre d’affichage des chain dans le mixer est le même que dans la vue Chain Manager. Pour déplacer une chain, sélectionnez longuement le bloc options de la chain (en haut de la chain). Cela active le mode de déplacement, indiqué par une bordure jaune. Vous pouvez alors utiliser le potentiomètre 4 pour déplacer la chain vers la gauche ou la droite, puis appuyer sur BACK pour quitter le mode de déplacement des chain.

Chain épinglées

Il est possible d’épingler des chain sur le côté droit de la vue Mixer, juste avant la chain principale. Cette option est purement visuelle. La zone située sous la chain principale a un arrière-plan plus sombre. Déplacez une chain dans cette zone pour l’épingler. Vous pouvez épingler les chain mixbus que vous utilisez comme retours d’effets.
