Vue de contrôle des chains

La vue de contrôle des chains permet d’accéder aux paramètres des processeurs de la chain active. Vous pouvez :

  • Modifier la valeur des paramètres des processeurs en tournant les boutons.
  • Passer en mode MIDI learn en appuyant brièvement sur le bouton 3.

Les paramètres des processeurs sont répartis sur des pages contenant jusqu’à 4 paramètres chacune. Sélectionnez les pages à l’aide des boutons S3 / S4. La liste contient les pages de contrôle de tous les processeurs de la chain.

Pour parcourir les pages plus rapidement, passez en mode de sélection en appuyant brièvement sur le bouton 4

Notez que le mode de sélection est également appelé vue de configuration de la chain.

MIDI Learn

Vous pouvez associer n’importe quel paramètre aux boutons, faders et pads CC de vos contrôleurs MIDI externes. Il existe 2 modes MIDI learn différents :

  • Chain Learn : L’association s’applique uniquement à la chain sélectionnée. Vous pouvez associer le même bouton à un ou plusieurs paramètres d’une même chain ou de chains différentes. Seule la chain sélectionnée réagira au message MIDI CC.
  • Global Learn : L’association est globale. Vous pouvez associer le même bouton à un ou plusieurs paramètres d’une même chain ou de chains différentes. Tous ces paramètres réagiront, quelle que soit la chain sélectionnée.
La procédure MIDI learn est la suivante :
  • Appuyez brièvement sur le bouton 3. Une indication ##?## s’affiche sur tous les paramètres pour signaler le mode Chain Learn. Si nécessaire, appuyez de nouveau pour passer en mode Global MIDI Learn. L’indication devient jaune : ??#??
  • Tournez le bouton associé au paramètre que vous souhaitez apprendre. L’indication « ??#?? » s’affiche uniquement sur ce paramètre, indiquant qu’il est en attente d’un MIDI learn.
  • Actionnez un bouton ou un fader ou tapez sur un pad CC de votre contrôleur MIDI externe. L’association est terminée et l’indication affiche alors le canal MIDI et le numéro de CC en blanc.

En mode MIDI learn, vous pouvez accéder aux options de contrôle des paramètres en appuyant longuement sur les boutons.

Vous pouvez annuler MIDI learn à tout moment en appuyant sur Retour.

Options de contrôle des paramètres

En mode MIDI learn, appuyez longuement sur n’importe quel bouton pour accéder aux options de contrôle du paramètre associé. Voici les options courantes :

  • Chain Controller : Lorsque cette option est cochée, le paramètre est ajouté aux pages du chain controller, au début de la liste des pages. Cette fonctionnalité permet de regrouper les « paramètres favoris » de la chain.
  • X-Y Touchpad : Lorsque des paramètres numériques ont été sélectionnés pour les axes X et Y, passez en mode X-Y Touchpad.
  • Chain Learn : Démarrer le MIDI learn de la chain pour le paramètre.
  • Global Learn : Démarrer le MIDI learn global pour le paramètre.
  • Zynstep CC : Choisir le numéro de CC utilisé par le séquenceur pour automatiser le paramètre.
  • Unlearn : Supprimer l’association du paramètre.
  • Unlearn all controls : Supprimer les associations de tous les paramètres du processeur.

Voici les options spécifiques aux contrôleurs numériques :

  • Mode absolu/relatif : Permet de configurer des boutons incrémentaux (encodeurs).
  • Plage de valeurs CC : Configurer le mappage des valeurs MIDI CC sur le paramètre associé.
  • Axe X : Cochez cette option pour utiliser le paramètre sur l’axe X en mode X-Y Touchpad.
  • Axe Y : Cochez cette option pour utiliser le paramètre sur l’axe Y en mode X-Y Touchpad.

Voici les options spécifiques aux contrôleurs à bascule :

  • Momentary => Latch : Interpréter les impulsions MIDI CC comme des bascules (mode latch).
  • Antirebond : Activer l’antirebond pour éviter les commutations intempestives.

X-Y Touchpad

En mode X-Y Touchpad, vous pouvez contrôler simultanément les 2 paramètres assignés en faisant glisser votre doigt sur l’écran tactile, comme sur un « chaos-pad ».
