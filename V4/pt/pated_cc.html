Editor de CC de pattern

O editor de CC de pattern permite automatizar alterações de parâmetros adicionando eventos MIDI CC aos seus patterns do sequenciador. O menu contextual (pressão breve no knob 1) permite modificar os parâmetros do pattern e as opções de edição.

O editor de CC também suporta a gravação em tempo real, anular/refazer e copiar/colar patterns, que funcionam de forma muito semelhante ao editor de notas.

Funcionamento básico

Para cada pattern, pode automatizar até 127 parâmetros utilizando os 127 números CC disponíveis.

Antes de poder automatizar um parâmetro, tem de atribuir os parâmetros que pretende automatizar aos números CC que pretende utilizar. Existem 2 formas de o fazer:

  • Utilize MIDI learning para atribuir parâmetros do engine a números CC. Para isso, precisará de um controlador MIDI com knobs ou faders.
  • No menu de opções dos parâmetros do engine, selecione ZynStep CC para atribuir manualmente um número CC.

Depois de atribuir o parâmetro que pretende automatizar, siga estes passos no editor de CC para criar manualmente o seu pattern CC:

  • Rode o knob 1 para selecionar o número CC que pretende editar. Se o CC já estiver atribuído, verá o nome do parâmetro.
  • Rode o knob 4 para deslocar o cursor ao longo do eixo temporal do pattern.
  • Prima brevemente o knob 4 para adicionar/remover um ponto da curva.
  • Rode o knob 3 para deslocar o ponto (valor CC) para cima e para baixo.
  • Prima brevemente S4 para voltar ao editor de notas.

Pode utilizar o dedo para desenhar a curva e deslocar os pontos para cima e para baixo. Também pode gravar em tempo real (REC + PLAY) e mover o knob atribuído no seu controlador MIDI.

Durante a reprodução, os valores CC são interpolados em cada clock tick (1920 ticks por semínima). A interpolação CC está ativada por predefinição, exceto para os pedais (ou seja, CC64).

No menu de opções do pattern, pode ativar ou desativar a interpolação CC individualmente para cada número CC, limpar o pattern CC mantendo as notas e muito mais.

Naturalmente, pode editar e ajustar parâmetros enquanto o pattern está a ser reproduzido, ouvindo imediatamente o resultado à medida que modifica os valores CC em tempo real.

Gravar patterns

Prima prolongadamente o knob 3 para ativar a gravação MIDI. Quando a gravação estiver armada, o símbolo de círculo amarelo acende-se na barra de estado.

Captura passo a passo

Não é suportada para eventos CC.

Captura em tempo real

Se o pattern estiver a ser reproduzido (prima brevemente o knob 3), os eventos de notas e CC serão capturados em tempo real. São gravados no momento exato em que são capturados, sem quantização. Se pretender, pode aplicar quantização durante a reprodução (consulte o menu de opções do pattern). Durante a captura em tempo real, o histórico é guardado em cada ciclo do pattern, mas apenas se forem capturadas notas novas.

Anular/Refazer

Pode anular/refazer a maioria das operações de edição através do seguinte procedimento:

  • Prima prolongadamente o knob 2 (BACK) para entrar no modo de navegação do histórico.
  • Rode o knob 4 para percorrer o histórico.
  • Prima brevemente o knob 2 (BACK) para terminar.

Embora o número de passos do histórico seja ilimitado, o histórico não é guardado no estado e perde-se quando voltar a carregar o snapshot. Os snapshots guardam apenas o último estado.

Opções do pattern

Prima brevemente o knob 1 para abrir o menu de opções do pattern, que permite modificar as propriedades do pattern e aceder a várias opções de edição. Estes são os parâmetros do pattern:

  • Renomear: Altera o nome da sequência apresentado nos pads do launcher.
  • Modo de reprodução: DESATIVADO, LOOP, ONE-SHOT, REPRODUZIR 2 VEZES, ... REPRODUZIR 24 VEZES
  • Program Change: O número de program-change acionado com o pattern. Pode ser utilizado para alterar ZS3s, etc.
  • Duração: A duração do pattern em compassos e tempos.
  • Passos/tempo: O número de passos por tempo. O passo é a unidade de tempo mais pequena na grelha do pattern, mas a posição e a duração dos eventos podem ser ajustadas em frações de passo.
  • Quantização: A quantização pode estar DESATIVADA ou definida para 1, 1/2, 1/3, 1/4 ou 1/6 de passo.
  • Intensidade do swing: A intensidade do swing em %.
  • Divisor do swing: O número de divisões utilizadas para o swing. Utilize 1 com 30% para obter um swing ternário perfeito.
  • Humanização do tempo: Aleatoriza o tempo das notas segundo uma distribuição gaussiana para simular imprecisão humana.
  • Interpolar valores CC##: Ativa ou desativa a interpolação do valor CC para o número CC selecionado.

Opções de edição

  • Copiar para a área de transferência: Copia o pattern para a área de transferência.
  • Colar da área de transferência: Cola o conteúdo da área de transferência no pattern atual.
  • Carregar pattern: Carrega um pattern de um ficheiro.
  • Guardar pattern: Guarda o pattern num ficheiro.
  • Importar de SMF: Carrega um pattern de um Standard MIDI File (.mid)
  • Exportar para SMF: Guarda o pattern num Standard MIDI File (.mid)
  • Limpar todo o pattern: Elimina todas as notas e eventos CC do pattern.
  • Limpar CC## do pattern: Elimina todos os eventos CC do número CC selecionado no pattern.
