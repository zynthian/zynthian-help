SooperLooper

Ein-Pedal-Modus

Sie können SooperLooper mit einem einzelnen MIDI-Pedal steuern. Binden Sie dazu das Pedal, das eine MIDI-CC-Nachricht sendet, an den Controller „single pedal“ auf der Seite „Global loop“ (6.) der Bedienelemente. Zynthian erwartet einen Wert ungleich null für CC, wenn das Pedal gedrückt wird, und den Wert null, wenn es losgelassen wird. Folgende Aktionen sind verfügbar:

  • Drücken im Ruhezustand, z. B. startet der erste Druck die Aufnahme der Loop.
  • Drücken während der Aufnahme beendet die Aufnahme und startet die Wiedergabe der Loop.
  • Drücken während der Wiedergabe startet das Overdubbing der Loop.
  • Doppeltes Drücken während der Wiedergabe pausiert die Loop.
  • Dreifaches Drücken löscht die Loop.
  • Doppeltes Drücken und Halten löscht die Loop.
  • Einmaliges Drücken und Halten nimmt auf oder overdubbt, bis das Pedal losgelassen wird.

MIDI CC für ausgewählte Loop

Jeder Encoder steuert die aktuell ausgewählte Loop. Jede von Ihnen erstellte MIDI-Zuweisung steuert ebenfalls die aktuell ausgewählte Loop. Dies wird durch die standardmäßig auf „on“ gesetzte Option „MIDI CC to selected loop“ auf der letzten Controller-Seite angezeigt.

Wenn Sie diese Option jedoch auf „off“ setzen, wird eine MIDI-Zuweisung beim Erstellen dem zu diesem Zeitpunkt ausgewählten Loop zugewiesen. Die betroffenen Bedienelemente zeigen die Nummer der aktuellen Loop in Klammern an.

Diese Zuweisung bleibt mit dieser Loop verknüpft, auch wenn Sie eine andere Loop auswählen. So können Sie mehrere Pedale bestimmten Loops zuweisen.

HINWEIS: Die Option muss auf „off“ stehen, damit die an eine Loop gebundene MIDI-Zuweisung ausgeführt wird. Für Zuweisungen im Modus „selected loop“ muss sie auf „on“ stehen.

ALT-Modus

SooperLooper verfügt über einen eigenen lokalen ALT-Modus. Dieser definiert die Funktion kurzer Tastendrücke bei Transport-, Pfeil- und F1-F4-Tasten neu:

HINWEIS: Damit diese Funktionen verfügbar sind, muss „MIDI-CC to selected loop“ wie oben beschrieben auf „on“ gesetzt sein.

  • REC
    • bei leerer Loop: schaltet die Aufnahme in der ausgewählten Loop ein oder aus
    • bei belegter Loop: schaltet das Overdubbing in der ausgewählten Loop ein oder aus
  • PLAY schaltet die Stummschaltung der ausgewählten Loop ein oder aus
  • STOP schaltet das Multiplizieren der ausgewählten Loop ein oder aus
  • F1 schaltet das Ersetzen in der ausgewählten Loop ein oder aus
  • F2 schaltet das Substituieren in der ausgewählten Loop ein oder aus
  • F3 schaltet das Einfügen in der ausgewählten Loop ein oder aus
  • F4 fügt eine neue leere Loop hinzu
  • LEFT macht den letzten Vorgang in der ausgewählten Loop rückgängig
  • RIGHT stellt den letzten Vorgang in der ausgewählten Loop wieder her
  • UP/DOWN wechselt die ausgewählte Loop
