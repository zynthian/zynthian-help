Pattern-CC-Editor

Mit dem Pattern-CC-Editor können Sie Parameteränderungen automatisieren, indem Sie MIDI-CC-Events zu Ihren Sequencer-Patterns hinzufügen. Über das Kontextmenü (OPT) können Sie die Pattern-Parameter und Bearbeitungsoptionen ändern.

Mit den PLAY/STOP-Tasten können Sie das Pattern wiedergeben/anhalten. Die REC-Taste aktiviert die MIDI-CC-Live-Aufnahme während der Wiedergabe (Echtzeit).

Im ALT-Modus stehen Sonderfunktionen wie Rückgängig/Wiederholen und das Kopieren/Einfügen von Patterns zur Verfügung.

Live-Aufnahme, Rückgängig/Wiederholen und das Kopieren/Einfügen von Patterns werden auch vom CC-Editor unterstützt und funktionieren weitgehend wie im Noteneditor.

Grundlegende Bedienung

Für jedes Pattern können Sie bis zu 127 Parameter mit den 127 verfügbaren CC-Nummern automatisieren.

Bevor Sie einen Parameter automatisieren können, müssen Sie die zu automatisierenden Parameter den gewünschten CC-Nummern zuweisen. Dafür gibt es zwei Möglichkeiten:

  • Verwenden Sie MIDI-Learning, um Engine-Parameter CC-Nummern zuzuweisen. Dazu benötigen Sie einen MIDI-Controller mit Drehreglern oder Fadern.
  • Wählen Sie im Optionsmenü des Engine-Parameters die Option ZynStep CC, um manuell eine CC-Nummer zuzuweisen.

Nachdem Sie den zu automatisierenden Parameter zugewiesen haben, gehen Sie im CC-Editor wie folgt vor, um Ihr CC-Pattern manuell zu erstellen:

  • Drehen Sie Regler 1, um die CC-Nummer auszuwählen, die Sie bearbeiten möchten. Wenn die CC bereits zugewiesen ist, wird der Parametername angezeigt.
  • Drehen Sie Regler 4, um den Cursor entlang der Zeitachse des Patterns zu bewegen.
  • Drücken Sie Regler 4 kurz, um einen Punkt zur Kurve hinzuzufügen oder daraus zu entfernen.
  • Drehen Sie Regler 3, um den Punkt (CC-Wert) nach oben oder unten zu bewegen.
  • Drücken Sie Regler 1 kurz, um zum Noteneditor zurückzukehren.

Sie können die Kurve mit dem Finger zeichnen und Punkte nach oben oder unten bewegen. Außerdem können Sie live aufnehmen (REC + PLAY) und den zugewiesenen Regler Ihres MIDI-Controllers bewegen.

Während der Wiedergabe werden CC-Werte bei jedem Clock-Tick interpoliert (1920 Ticks pro Viertelnote). Die CC-Interpolation ist standardmäßig aktiviert, außer bei Pedalen (z. B. CC64).

Im Pattern-Optionsmenü können Sie die CC-Interpolation für jede CC-Nummer einzeln umschalten, das CC-Pattern löschen, ohne die Noten zu entfernen, und vieles mehr.

Selbstverständlich können alle Bearbeitungen und Parameteranpassungen während der Pattern-Wiedergabe vorgenommen werden. So hören Sie das Ergebnis sofort, während Sie die CC-Werte in Echtzeit ändern.

Patterns aufnehmen

Drücken Sie die REC-Taste, um die MIDI-Aufnahme zu aktivieren. Wenn die Aufnahme scharfgeschaltet ist, leuchtet die REC-Taste rot.

Schrittweise Aufnahme

Für CC-Events wird diese Funktion nicht unterstützt.

Live-Aufnahme

Wenn das Pattern wiedergegeben wird, werden Noten- und CC-Events in Echtzeit aufgenommen. Sie werden exakt zum Zeitpunkt ihrer Aufnahme erfasst, ohne Quantisierung. Bei Bedarf kann die Quantisierung bei der Wiedergabe angewendet werden (siehe Pattern-Optionsmenü). Während der Live-Aufnahme wird der Verlauf bei jeder Pattern-Wiederholung gespeichert, jedoch nur, wenn neue Noten aufgenommen wurden.

Rückgängig/Wiederholen

Im ALT-Modus können Sie mit den Pfeiltasten Aktionen rückgängig machen oder wiederholen:

  • LEFT: Letzten Bearbeitungsschritt rückgängig machen.
  • RIGHT: Letzten rückgängig gemachten Schritt wiederholen.
  • DOWN: ALLES rückgängig machen.
  • UP: ALLES wiederholen.

Für Rückgängig/Wiederholen gibt es außerdem einen alternativen Ablauf, der die Bedienung erleichtert oder verwendet werden kann, wenn der ALT-Modus nicht ohne Weiteres verfügbar ist:

  • Wenn die Aufnahme scharfgeschaltet ist (REC-Taste leuchtet rot) …
  • Halten Sie die BACK-Taste gedrückt, um den Verlaufsmodus aufzurufen.
  • Drehen Sie Regler 4, um sich im Verlauf zu bewegen.
  • Drücken Sie BACK, um den Modus zu verlassen.

Beachten Sie, dass zwar die Anzahl der Verlaufsschritte unbegrenzt ist, der Verlauf jedoch nicht im Zustand gespeichert wird und verloren geht, wenn Sie den Snapshot erneut laden. Snapshots speichern nur den letzten Zustand.

Pattern-Optionen

Drücken Sie ALT kurz, um das Menü Pattern-Optionen zu öffnen. Dort können Sie die Pattern-Eigenschaften sowie verschiedene Bearbeitungsoptionen ändern. Folgende Pattern-Parameter stehen zur Verfügung:

  • Rename: Ändert den Namen der Sequenz, der auf den Pads des Launchers angezeigt wird.
  • Play mode: DISABLED, LOOP, ONE-SHOT, PLAY 2 TIMES, ... PLAY 24 TIMES
  • Program Change: Die Program-Change-Nummer, die mit dem Pattern ausgelöst wird. Sie kann beispielsweise zum Wechseln von ZS3s verwendet werden.
  • Length: Die Pattern-Länge in Takten und Taktschlägen.
  • Steps/Beat: Die Anzahl der Steps pro Taktschlag. Der Step ist die kleinste Zeiteinheit im Pattern-Raster; die Position und Dauer eines Events können jedoch auch in Bruchteilen eines Steps angepasst werden.
  • Quantization: Die Quantisierung kann deaktiviert oder auf 1, 1/2, 1/3, 1/4 oder 1/6 Step eingestellt werden.
  • Swing Amount: Die Stärke des Swings in %.
  • Swing Divisor: Die Anzahl der Unterteilungen für den Swing. Verwenden Sie den Wert 1 mit 30 %, um einen perfekten ternären Swing zu erzielen.
  • Time Humanization: Variiert den Zeitpunkt der Noten gemäß einer Gauß-Verteilung, um menschliche Ungenauigkeiten zu simulieren.
  • Interpolate CC## values: Schaltet die CC-Wert-Interpolation für die ausgewählte CC-Nummer um.

Bearbeitungsoptionen

  • Copy this to clipboard: Kopiert das Pattern in die Zwischenablage.
  • Paste from clipboard: Fügt den Inhalt der Zwischenablage in das aktuelle Pattern ein.
  • Load pattern: Lädt ein Pattern aus einer Datei.
  • Save pattern: Speichert das Pattern in einer Datei.
  • Import from SMF: Lädt ein Pattern aus einer Standard-MIDI-Datei (.mid).
  • Export to SMF: Speichert das Pattern als Standard-MIDI-Datei (.mid).
  • Clear pattern ALL: Löscht alle Noten- und CC-Events aus dem Pattern.
  • Clear pattern CC##: Löscht alle CC-Events der ausgewählten CC-Nummer aus dem Pattern.
