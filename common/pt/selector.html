Vista do seletor

O selector é uma vista genérica utilizada para apresentar uma lista de opções selecionáveis. A lista pode incluir cabeçalhos não selecionáveis que dividem as respetivas secções.

Ao selecionar uma entrada, pode navegar para outra vista, alternar uma opção ou abrir o editor de parâmetros. Rode o botão 4 para percorrer a lista e prima para selecionar o item. Poderão estar disponíveis ações alternativas através de uma pressão prolongada. Utilize BACK para sair.

No painel lateral direito, por baixo do ícone, são apresentadas sugestões ou informações que descrevem o item selecionado. Se o texto for demasiado longo, pode percorrê-lo com o botão 3. Prima o botão 3 para ver mais detalhes, se disponíveis.
