Vista de presets

La vista de presets permite gestionar los presets del procesador. Para acceder a la vista de presets del procesador activo:

  • En las vistas chain-control o chain-config, mantenga pulsado el knob-4.

Tenga en cuenta que el procesador activo es el que aparece resaltado en la chain activa.

Una vez en la vista de presets, puede:

  • Girar el knob-4 para explorar la lista. Si está activado preset preload (consulte la vista de administración), el preset resaltado se precargará al desplazarse por la lista.
  • Pulsar brevemente el knob-4 para seleccionar un preset para el procesador y cerrar la vista.
  • Mantener pulsado el knob-4 para abrir las opciones del preset.
  • Pulsar brevemente el knob-2 (BACK) para acceder a la lista de bancos. Pulse brevemente BACK de nuevo para salir de la selección de banco/preset.

Las opciones de los presets pueden variar según el procesador. Estas son las opciones habituales:

  • [ ] Favorite => Marque la casilla para añadir el preset a la lista de favoritos.
  • Save as new preset => Guarde los ajustes actuales de los parámetros como un nuevo preset.
  • Delete preset => Elimine el preset. Solo está disponible para los presets de usuario.
  • Scan for new presets => Por ejemplo, cuando instale o cree presets desde webconf.
