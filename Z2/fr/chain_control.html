Vue de contrôle de chain

La vue de contrôle de chain permet d’accéder aux paramètres des processeurs de la chain active. Vous pouvez :

  • Modifier la valeur des paramètres des processeurs en tournant les potentiomètres.
  • Effectuer le MIDI-learn des paramètres en appuyant brièvement sur les potentiomètres
  • Configurer les options de contrôle des paramètres en appuyant longuement sur les potentiomètres.

Les paramètres des processeurs sont regroupés sur des pages contenant jusqu’à 4 paramètres chacune. Sélectionnez les pages à l’aide des boutons UP / DOWN. La liste contient les pages de contrôle de tous les processeurs de la chain.

Pour parcourir les pages plus rapidement, passez en mode de sélection en :

  • appuyant brièvement sur SELECT
    • ou
  • appuyant brièvement sur OPT

Notez que le mode de sélection est également appelé vue chain config.

MIDI-learn

Vous pouvez associer n’importe quel paramètre aux potentiomètres, curseurs et pads CC de vos contrôleurs MIDI externes. Il existe 2 modes de MIDI-learn :

  • Chain Learn : L’association est limitée à la chain sélectionnée. Vous pouvez associer le même potentiomètre à un ou plusieurs paramètres dans la même chain ou dans différentes chains. Seule la chain sélectionnée réagit au message MIDI CC.
  • Global Learn : L’association est globale. Vous pouvez associer le même potentiomètre à un ou plusieurs paramètres dans la même chain ou dans différentes chains. Tous réagiront, quelle que soit la chain sélectionnée.
La procédure de MIDI-learn est la suivante :
  • Appuyez brièvement sur le potentiomètre associé au paramètre que vous souhaitez configurer. Un indicateur vert ??#?? s’affiche pour indiquer que le paramètre est en mode d’apprentissage chain.
  • Si nécessaire, appuyez de nouveau brièvement pour passer en mode d’apprentissage global. L’indicateur devient jaune, comme ceci : ??#??
  • Déplacez un potentiomètre ou un curseur ou touchez un pad CC sur votre contrôleur MIDI externe. L’association est terminée et l’indicateur affiche alors le canal MIDI et le numéro CC en blanc.

Options de contrôle des paramètres

Appuyez longuement sur n’importe quel potentiomètre pour accéder aux options du contrôleur associé au paramètre. Voici les options courantes :

  • Chain Controller : Lorsque cette option est cochée, le paramètre est ajouté aux pages du chain controller, au début de la liste des pages. Cette fonction agit comme une sorte de « paramètres favoris » pour la chain.
  • Pavé tactile X-Y : Lorsque des paramètres numériques ont été sélectionnés pour les axes X et Y, passez en mode Pavé tactile X-Y.
  • Chain Learn : Démarrer le MIDI-learn Chain pour le paramètre.
  • Global Learn : Démarrer le MIDI-learn Global pour le paramètre.
  • Zynstep CC : Choisir le numéro CC utilisé par le séquenceur pour automatiser le paramètre.
  • Unlearn : Supprimer l’apprentissage du paramètre.
  • Unlearn all controls : Supprimer l’apprentissage de tous les paramètres du processeur.

Voici les options spécifiques aux contrôleurs numériques :

  • Mode absolu/relatif : Permet de configurer les potentiomètres incrémentaux (encodeurs).
  • Plage de valeurs CC : Configurer la correspondance entre les valeurs MIDI CC et le paramètre associé.
  • Axe X : Cochez cette option pour utiliser le paramètre sur l’axe X en mode Pavé tactile X-Y.
  • Axe Y : Cochez cette option pour utiliser le paramètre sur l’axe Y en mode Pavé tactile X-Y.

Voici les options spécifiques aux contrôleurs à bascule :

  • Momentary => Latch : Interpréter les impulsions MIDI CC comme des bascules (mode latch).
  • Anti-rebond : Activer l’anti-rebond pour éviter les commutations intempestives.

Pavé tactile X-Y

En mode Pavé tactile X-Y, vous pouvez contrôler simultanément les 2 paramètres attribués en faisant glisser votre doigt sur l’écran tactile, « à la manière d’un chaos-pad ».
