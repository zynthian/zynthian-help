Tempo View

The tempo view provides control of zynthian's timebase used for sequencing, arpeggiators, etc.

Rotate knob 1 to adjust the BPM value between 10 and 420 BPM. Push and rotate to adjust in 0.1 BPM steps. Note that BPM tempo can be automated using launcher phrases. This control is only available when using internal clock.

Rotate knob 2 to adjust the Metronome Mode control configures the zynthian's metronome. It has these values:

  • OFF: Metronome is disabled.
  • AUTO: Metronome will sound when there is a sequence playing and stop at the end of the bar after the last sequence stops.
  • ON: Metronome plays continuously.
  • INTRO: Metronome plays until a sequence starts. You may use this as a count-in when you don't want or need the metronome to play during performance.
  • NO ACCENT: Metronome plays continually but with without an accent on the first beat of each bar. This acts more like a traditional metronome used purely for tempo and not timebase.
  • SILENT: Metronome runs but does not make any sound. This can be useful to cause the transport to run when there are no sequences running. Some plugins may benefit from this.

Rotate knob 3 to adjust the metronome volume level.

Note: The metronome click-sound feeds the main chain, via its auxiliary mix feed which allows individual control of level, balance, etc. The global audio player shares this aux mix.

Rotate knob 4 to change the time signature (beats per bar). Time signature changes are applied at the beginning of next bar.

Note: Tempo (BPM) and time signature (beats/bar) can be automated using launcher phrases.

External Clock

If an external clock is used, the BPM control is replaced by the Clock Divider. Default clock divider's value is 24 PPQN, which is what MIDI clock uses but may be adjusted to support other external clock rates in the range of 1 to 48 PPQN.

The internal clock runs at 1920 PPQN and uses a phase locked loop (PLL) to derive this high resolution clock from the slow input clock. To use an external clock, select "MIDI Clock Source" for a MIDI input in the MIDI Input view.

Tap-Tempo

There is a large display with the BPM value which may be tapped to set the tempo. Similarly, the tempo button may be tapped to set the tempo too.
