Vista de presets

A vista de presets permite gerir os presets do processador. Para aceder à vista de presets do processador ativo:

  • Nas vistas chain-control ou chain-config, prima longamente o knob-4.

Tenha em atenção que o processador ativo é o processador destacado na chain ativa.

Na vista de presets, pode:

  • Rodar o knob-4 para percorrer a lista. Se a opção preload de presets estiver ativada (consulte a vista de administração), o preset destacado será pré-carregado ao percorrer a lista.
  • Premir brevemente o knob-4 para selecionar um preset para o processador e fechar a vista.
  • Premir longamente o knob-4 para abrir as opções do preset.
  • Premir brevemente o knob-2 (BACK) para aceder à lista de bancos. Prima brevemente BACK novamente para sair da seleção de banco/preset.

As opções dos presets podem variar consoante o processador. Estas são as opções típicas:

  • [ ] Favorite => Selecione esta opção para adicionar o preset à lista de favoritos.
  • Save as new preset => Guardar os ajustes atuais dos parâmetros como um novo preset.
  • Delete preset => Eliminar o preset. Disponível apenas para presets do utilizador.
  • Scan for new presets => Por exemplo, quando instala/cria presets através do webconf.
