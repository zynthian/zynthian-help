Vue de configuration de chain

La vue de configuration de chain, également appelée mode de sélection, permet de configurer tous les aspects d'une chain.

Le panneau de gauche contient la liste des blocs qui configurent votre chain, y compris les processeurs. Le panneau de droite affiche une version réduite de la vue de contrôle de chain. Utilisez le bouton 3 pour parcourir les blocs de chain à gauche et le bouton 4 pour parcourir la liste de droite.

Pour quitter, il suffit d'effectuer une pression brève sur BACK afin de revenir à la vue de contrôle de chain.

Les blocs de chain du panneau de gauche fonctionnent comme ceux de la vue de gestion des chains et dépendent du type de chain et des processeurs. Il peut s'agir de :

  • Options de chain
  • MIDI Input
  • Audio Input
  • MIDI Processors
  • Synth Processor
  • Audio Processors
  • MIDI Output
  • Audio Output

Blocs de processeur

Lorsqu'un processeur est sélectionné, la liste de droite se repositionne pour afficher les pages de paramètres de ce processeur. Vous pouvez accéder aux options du processeur en effectuant une pression brève sur le bouton 3, une pression brève sur OPT ou un deuxième appui bref sur le bloc sur un écran tactile.

Blocs autres que des processeurs

Lorsqu'un bloc autre qu'un processeur est sélectionné, par exemple Options de chain, MIDI Input, etc., un panneau de configuration s'affiche dans le panneau de droite. Vous pouvez parcourir les options en tournant le bouton 4 et sélectionner/activer les options en effectuant une pression brève sur le bouton 4. Vous pouvez également utiliser les boutons UP/DOWN et SELECT. Si une option comporte des sous-options, vous pouvez accéder au menu correspondant en effectuant une pression longue sur le bouton 4, une pression longue sur SELECT ou une pression brève sur OPT.
