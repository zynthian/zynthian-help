Chain-Steuerungsansicht

In der Chain-Steuerungsansicht können Sie auf die Parameter der Prozessoren in der aktiven Chain zugreifen. Sie können:

  • den Wert von Prozessorparametern ändern, indem Sie die Regler drehen.
  • für Parameter MIDI-Learn ausführen, indem Sie die Regler kurz drücken
  • Steuerungsoptionen für Parameter konfigurieren, indem Sie die Regler kräftig drücken.

Die Prozessorparameter sind seitenweise gruppiert, mit bis zu 4 Parametern pro Seite. Wählen Sie Seiten mit den Tasten UP / DOWN aus. Die Liste enthält die Steuerungsseiten für alle Prozessoren in der Chain.

Um schneller zwischen den Seiten zu wechseln, wechseln Sie mit einer der folgenden Aktionen in den Auswahlmodus:

  • SELECT kurz drücken
    • oder
  • OPT kurz drücken

Beachten Sie, dass der Auswahlmodus auch als Ansicht Chain-Konfiguration bezeichnet wird.

MIDI-Learn

Sie können beliebige Parameter den Reglern, Fadern und CC-Pads Ihrer externen MIDI-Controller zuweisen. Es gibt zwei verschiedene MIDI-Learn-Modi:

  • Chain Learn: Die Zuweisung gilt nur für die ausgewählte Chain. Sie können denselben Regler einem oder mehreren Parametern in derselben oder in verschiedenen Chains zuweisen. Nur die ausgewählte Chain reagiert auf die MIDI-CC-Nachricht.
  • Global Learn: Die Zuweisung gilt global. Sie können denselben Regler einem oder mehreren Parametern in derselben oder in verschiedenen Chains zuweisen. Alle zugewiesenen Parameter reagieren, unabhängig davon, welche Chain ausgewählt ist.
So führen Sie MIDI-Learn aus:
  • Drücken Sie den Regler des Parameters, den Sie zuweisen möchten, kurz. Eine grüne Anzeige ??#?? wird eingeblendet und zeigt an, dass sich der Parameter im Chain-Lernmodus befindet.
  • Drücken Sie den Regler bei Bedarf erneut kurz, um in den globalen Lernmodus zu wechseln. Die Anzeige wechselt zu Gelb, wie hier: ??#??
  • Bewegen Sie einen Regler oder Fader oder tippen Sie auf ein CC-Pad Ihres externen MIDI-Controllers. Die Zuweisung ist abgeschlossen. Die Anzeige zeigt nun den MIDI-Kanal und die CC-Nummer in Weiß an.

Steuerungsoptionen für Parameter

Drücken Sie einen beliebigen Regler kräftig, um die Controller-Optionen für den zugehörigen Parameter aufzurufen. Zu den allgemeinen Optionen gehören:

  • Chain Controller: Wenn diese Option aktiviert ist, wird der Parameter am Anfang der Seitenliste zu den Chain-Controller-Seiten hinzugefügt. Diese Funktion dient als eine Art „Favoritenparameter“ für die Chain.
  • X-Y-Touchpad: Wenn numerische Parameter für die X- und Y-Achse ausgewählt wurden, wechseln Sie in den X-Y-Touchpad-Modus.
  • Chain Learn: MIDI-Learn für den Parameter im Chain-Modus starten.
  • Global Learn: MIDI-Learn für den Parameter im globalen Modus starten.
  • Zynstep CC: CC-Nummer auswählen, die der Sequencer zur Automatisierung des Parameters verwendet.
  • Unlearn: MIDI-Zuweisung des Parameters aufheben.
  • Unlearn all controls: MIDI-Zuweisungen aller Parameter im Prozessor aufheben.

Für numerische Controller gibt es folgende spezifische Optionen:

  • Absolute/Relative Mode: Inkrementelle Regler (Encoder) konfigurieren.
  • CC Value Range: Festlegen, wie MIDI-CC-Werte dem zugehörigen Parameter zugeordnet werden.
  • X-axis: Aktivieren, um den Parameter im X-Y-Touchpad-Modus für die X-Achse zu verwenden.
  • Y-axis: Aktivieren, um den Parameter im X-Y-Touchpad-Modus für die Y-Achse zu verwenden.

Für Umschalt-Controller gibt es folgende spezifische Optionen:

  • Momentary => Latch: MIDI-CC-Impulse als Umschaltvorgänge interpretieren (Latch-Modus).
  • Debounce: Entprellung aktivieren, um unbeabsichtigtes Umschalten zu vermeiden.

X-Y-Touchpad

Im X-Y-Touchpad-Modus können Sie die beiden zugewiesenen Parameter gleichzeitig mit dem Finger auf dem Touchscreen steuern – wie bei einem „Chaos-Pad“.
