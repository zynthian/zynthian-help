The User Interface

The zynthian V5 user interface is managed primarily with:

  • 4 knobs with switch
  • 20 buttons with RGB LEDs
  • capacitive multi-touch display

Alternately, the zynthian UI can be managed:

  • using the VNC interface
  • with a supported MIDI controller
  • with MIDI notes in the MIDI master channel
  • with a computer keyboard (key bindings)
  • using OSC CUIA

This guide covers only the primary UI using knobs, buttons and touch interactions. For the rest, please, visit the zynthian wiki.

Knob Actions

There are five knob actions:

  • Short Press: Pressing a knob for less of 0.3 seconds triggers the short press action(*).
  • Bold Press: Pressing a knob for more than 0.3 and less than 2 seconds triggers the bold press action(*).
  • Long Press: Pressing and holding a knob for more than 2 seconds triggers the long press action(*).
  • Rotate: Rotating a knob may adjusts a parameter value, change the selected item on a list or move the cursor horizontal or vertically. Knob acceleration allows for finer adjustment at slow rotation and coarser adjustment at faster rotation.
  • Press + Rotate: Rotating a knob whilst it is pressed may increase the resolution, allowing for fine adjustment.

Button Actions

There are three button actions:

  • Short Press: Pressing a button for less of 0.3 seconds triggers the short press action (*).
  • Bold Press: Pressing a button for more than 0.3 and less than 2 seconds triggers the bold press action(*).
  • Long Press: Pressing and holding a button for more than 2 seconds triggers the long press action(*).

(*) The timing for the press actions can be configured from the webconf tool, in the advanced UI options tab.

Note that not all knobs/buttons have mapped functions for each action type. Knob/button actions can change their function depending of the context. This is well documented across the help pages for the different views. Remember the action icons shown above as they would be used along this guide.

Finally, you can modify the default action map from the webconf tool, accessing the advanced options in the wiring layout section. We don't recommend you do it, but up to you!

Using the knobs

The V5 knobs behave quite differently from the V1-V4 knobs. Because of the 20 silicone buttons, there is no need to use the knobs' switches to navigate the UI which now is best achieved with the push buttons, so knobs' switches have been mapped to more contextual functions, like MIDI learning. The knobs are numbered from top to bottom, so the top one is knob #1 and the bottom one is knob #4. We will refer knobs in this way throughout this guide.

General rule

Although knobs' behavior is contextual, there is a pattern that can serve as a general rule and applies to many views:

Knob #4

  • On selector views (lists):
    • Rotate to browse the list.
    • Short press to select items, like the SEL button.
    • Bold press to open contextual options, like the OPT button.
  • On grid views, it's the X-axis knob. Rotate to move the cursor horizontally.
  • On splitted views with 2 scrollable lists, it manages the list at right.

Knob #3

  • On grid views, it's the Y-axis knob. Rotate to move the cursor vertically.
  • On splitted views with 2 scrollable lists, it manages the list at left.
    • Rotate to browse the list at left.
    • Short press to select in the list at left.
The main volume is always available with one click. Short press MIX button, then rotate Knob 3 to change the main volume.

Using the push buttons

The V5 push buttons grid is divided in 5 groups. The picture shows the 5 groups outlined with different colors:

  • View buttons => Green
  • ALT button => Purple
  • Transport buttons => Red
  • Navigation buttons => Yellow
  • Function buttons => Blue

View buttons

View buttons are outlined in green in the picture and they allow direct access to the main views. Most of these buttons have 2 views assigned with a horizontal line separating the two printed labels. The primary view is printed at top and the secondary view is printed at bottom. The "metronome" button is the exception.

Short-push on the button to access:

  • the primary view, when the button's primary view is not shown
  • the secondary view, when button's primary view is shown

LED color depends of the current view:

  • when the primary view is shown, the button lights green.
  • when the secondary view is shown, the button lights orange.
  • when none of the button's views are shown, the button lights blue.
Remember, short-push to access the primeray view, push again to access the secondary view. Bold-push to access the secondary view, no matter the what current view is.

The view buttons are, from left to right and top to bottom:

  • OPT/ADMIN
    • Primary: Contextual Options / Main Menu
    • Secondary: Admin Menu
  • MIX/LEVEL
    • Primary: Mixer view
    • Secondary: Audio Levels
    • CTRL/PRESET
    • Primary: Chain Control view
    • Secondary: Bank/Preset selection
    • ZS3/SNAPSHOT
    • Primary: ZS3s list
    • Secondary: Snapshots list
    • METRONOME
    • First push: Tempo view
    • Next taps: Tap tempo. Adjust tempo BPM.
    • PAD/STEP
    • Primary: Launcher view
    • Secondary: Pattern editor

ALT button

The ALT button have 2 functions:

  • short-push to toggle the ALT mode (alternate function mode).
  • bold-push to open the on-screen contextual help.

ALT mode

When you the ALT mode, the ALT button and the buttons having an alternate function will change their default color from blue to purple or orange. Purple denotes default alt function. Orange denotes custom alt function.

ALT mode is contextual, depending of the current view. By default, only transport and function buttons (F1-F4) have alternate functions, defined like this:

  • Transport buttons toggle between Audio Player/Recorder (normal) and MIDI Player/Recorder (alt).
  • F1-F4 buttons toggle between programs 1-4 (normal) and programs 5-8 (alt). You could use it, for instance, to learn and recall up to 8 subsnapshots (ZS3s).

Some views have a custom ALT mode with specific functionality that partial or totally overrides the defaults. ALT mode state is kept for each view. The details about the custom ALT modes are documented for each view separately.

Contextual Help

Bold-push ALT button to open the contextual help for the current view. From the help screen you can:

  • Rotate knob 4 or push UP/DOWN buttons to scroll the contents.
  • Short-push knob 4 to browse the links.
  • Short-push BACK to back to the previous page or exit the help screen.

Transport buttons

By default, transport buttons control the global audio recorder/player and the default color is blue. When ALT mode is enabled, transport buttons control the MIDI recorder/player and the color is purple.

  • short-push REC to start/stop a recording. When a recording is in progress, the record button lights red and you should also see the rec icon in the display status area, at top-right.
  • short-push PLAY to play/pause the currently selected track. The last recorded track is selected by default. When a track is being played, the play button lights green. After pausing, pushing again will resume playing at the point it was paused.
  • bold-push PLAY to open the track list. After selecting a track, the audio player control view will be shown.
  • short-push STOP to stop playing a track and rewind. Pushing play again will start playing from the beginning.
  • bold-push STOP to stop all sounds, including any audio/MIDI track and sequences. PANIC!

In some views, transport buttons have specific (contextual) behaviour. When this happens, they will light orange to denote their normal behavior is altered. See the specific view section to have the details.

Navigation buttons

Navigation buttons are used for basic navigation and operation:

  • UP/DOWN
    • Browse lists and menus
    • Move cursor (selected item) vertically in grid views: pattern editor, launcher, etc.
  • LEFT/RIGHT
    • Select active chain in the mixer and chain-control views.
    • Move cursor (selected item) horizontally in grid views: pattern editor, launcher, etc.
  • SEL/YES
    • Select items in lists and menus.
    • Enter select mode in chain-control view for browsing controller pages.
    • Add/remove notes in pattern editor.
    • Play/stop phrases, sequences or audio clips in the launcher.
    • Answer "Yes" in confirmation dialogs.
    • Bold-push may open the options menu for the selected item.
  • BACK/NO
    • Close current view, returning to previous view.
    • Answer "No" in confirmation dialogs.

Function buttons (F1-F4)

These buttons are considered to be customizable buttons, e.g. if you want direct access to other views, etc. you may reconfigure these buttons using the webconf tool.

As explained above, while describing the ALT-mode, these buttons are assigned by default to MIDI Program Change messages:

  • Normal mode: Program Change 1-4
  • ALT mode: Program Change 5-8

This default configuration is fine for learning/recalling subsnapshots (ZS3) and you may find this really useful if you use your zynthian as a keyboard expander.

Some views have custom ALT modes that redefine F1-F4 button functionality. For instance, the launcher view or the pattern editor.

Although all buttons and switches are fully configurable from the webconf tool, this guide refers to the official V5 profile configuration, that matches printed button legends. Of course, you are very welcome to experiment with button assignment and try different configurations.

Global functions

Some buttons have a global tertiary function assigned to the long-push action:

  • BACK/NO: long-push to access the power off menu.
  • CTRL/PRESET: long-push to access preset favorites.
  • STOP: long-push to totally stop all sounds. SUPER PANIC!
  • F4: long-push to toggle the TTS interface (Text-To-Speech).
