Vista de controlo da chain

A vista de controlo da chain permite aceder aos parâmetros dos processadores na chain ativa. Pode:

  • Modificar o valor dos parâmetros dos processadores rodando os encoders.
  • Efetuar MIDI-learn dos parâmetros premindo brevemente os encoders
  • Configurar as opções de controlo dos parâmetros premindo demoradamente os encoders.

Os parâmetros dos processadores estão agrupados em páginas com até 4 parâmetros por página. Selecione as páginas utilizando os botões UP / DOWN. A lista contém as páginas de controlo de todos os processadores da chain.

Para percorrer as páginas mais rapidamente, aceda ao modo de seleção com:

  • premir brevemente SELECT
    • ou
  • premir brevemente OPT

Note que o modo de seleção também é conhecido como vista chain config.

MIDI-learn

Pode associar qualquer parâmetro a encoders, faders e pads CC dos seus controladores MIDI externos. Existem 2 modos de MIDI-learn diferentes:

  • Chain Learn: A associação aplica-se apenas à chain selecionada. Pode associar o mesmo controlo a um ou vários parâmetros na mesma chain ou em chains diferentes. Apenas a chain selecionada irá reagir à mensagem MIDI CC.
  • Global Learn: A associação é global. Pode associar o mesmo controlo a um ou vários parâmetros na mesma chain ou em chains diferentes. Todos irão reagir, independentemente da chain selecionada.
O procedimento de MIDI-learn é o seguinte:
  • prima brevemente o encoder associado ao parâmetro que pretende configurar. Será apresentado um indicador verde ??#?? para indicar que o parâmetro está no modo Chain Learn.
  • se necessário, prima novamente brevemente para entrar no modo Global Learn. O indicador ficará amarelo, como neste exemplo: ??#??
  • mova um encoder/fader ou toque num pad CC do seu controlador MIDI externo. A associação fica concluída e o indicador apresenta agora o canal MIDI e o número CC a branco.

Opções de controlo dos parâmetros

Prima demoradamente qualquer encoder para aceder às opções do controlador do parâmetro associado. Estas são as opções comuns:

  • Chain Controller: Quando ativada, esta opção adiciona o parâmetro às páginas do chain controller, no início da lista de páginas. Esta funcionalidade permite criar uma espécie de «parâmetros favoritos» para a chain.
  • Touchpad X-Y: Quando tiver selecionado parâmetros numéricos para os eixos X e Y, entre no modo Touchpad X-Y.
  • Chain Learn: Inicia o MIDI-learn Chain para o parâmetro.
  • Global Learn: Inicia o MIDI-learn Global para o parâmetro.
  • Zynstep CC: Escolha o número CC utilizado pelo sequenciador para automatizar o parâmetro.
  • Desassociar: Desassocia o parâmetro.
  • Desassociar todos os controlos: Desassocia todos os parâmetros do processador.

Estas são as opções específicas dos controladores numéricos:

  • Modo absoluto/relativo: Permite configurar encoders incrementais.
  • Intervalo de valores CC: Configure a forma como os valores MIDI CC são mapeados para o parâmetro associado.
  • Eixo X: Ative para utilizar o parâmetro no eixo X do modo Touchpad X-Y.
  • Eixo Y: Ative para utilizar o parâmetro no eixo Y do modo Touchpad X-Y.

Estas são as opções específicas dos controladores de alternância:

  • Momentâneo => com retenção: Interprete os impulsos MIDI CC como alternâncias (modo com retenção).
  • Debounce: Ative a filtragem de ressaltos para evitar comutações espúrias.

Touchpad X-Y

No modo Touchpad X-Y, pode controlar os 2 parâmetros atribuídos em simultâneo deslizando o dedo no ecrã tátil, «à la chaos-pad».
