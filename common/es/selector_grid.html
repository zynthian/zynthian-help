Vista de cuadrícula del selector

La cuadrícula del selector es una vista genérica que se utiliza para mostrar una cuadrícula de opciones seleccionables. Cada elemento de la cuadrícula tiene una imagen y un título.

Al seleccionar una opción, puede abrirse otra vista, activarse o desactivarse una opción o abrirse el editor de parámetros. Gire el mando 4 para recorrer la lista y pulse para seleccionar el elemento. Puede haber acciones alternativas disponibles al mantener pulsado. Use BACK para salir.
